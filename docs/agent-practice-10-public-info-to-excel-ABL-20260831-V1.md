# AI实战10｜别再手工复制网页：让Agent把公开信息直接整理成Excel

公开网站上的名单、公告、项目数据，经常需要手工复制进Excel。只要字段和来源规则明确，这类工作非常适合Agent批量抓取和整理。

## 一、先定义字段再开始搜

例如公司、板块、日期、项目状态、律师事务所、公告链接。先定字段可以避免搜到一半才发现数据不可比较。

## 二、每条数据保留来源

网页内容会更新，整理时应保留原始网址、发布日期或抓取日期。遇到同一事项多个页面时优先官方原文并去重。

## 三、不要把搜索结果当事实

主体、日期、金额等关键字段要打开页面核验；无法确认的字段留空或标记，不要为了表格完整而猜。

## 直接复制的实战提示词

请从【指定网站/公开信息范围】批量整理【目标事项】，统一提取【字段列表】并写入【Excel文件.xlsx】。每条记录必须保留原始来源和发布日期/抓取日期，优先使用官方原文并去重。对同名主体、冲突数据或无法确认字段单独标记【待核验】，不得仅根据搜索摘要填表。完成后检查记录总数、重复项和关键字段缺失。

## 最后记住一句话

网页整理真正值得自动化的是：**从“复制粘贴”变成“有来源的结构化数据”。**
