# AI实战48｜项目不用天天自己盯：让Agent每周自动做一次项目巡检

长期IPO、尽调、并购、诉讼或顾问项目最容易出现的问题不是不会做，而是做着做着不知道还有什么没解决。第二类定时任务，可以让Agent每周自动做一次项目巡检。

## 一、第一次先建立项目基准状态

读取尽调清单、任务表、法律意见书、问询回复、客户回复等，理解项目当前做到哪里。之后每周主要比较变化。

## 二、检查资料和待办

哪些清单事项已完成、部分完成或未提供；报告里还有多少【待核验】【待补充】【待客户确认】和批注。

## 三、检查新增材料有没有真正进入成果

客户本周补了许可证、合同、诉讼更新，但法律意见书是否同步？材料收到了不等于工作完成了。

## 四、检查版本和跨文件同步

识别核心文件多个近似版本、不同文件关键事实或数字未同步等异常，但不要自动删除或选择主版本。

## 五、检查期限和长期卡点

未来7天、14天、30天有什么截止；上周已经提示的问题这周是否仍未解决。连续多周无进展的事项应升级提醒。

## 六、最后给下周优先级和律师确认项

只输出变化、异常、未解决、临近期限和需要决定的问题，正常事项不用每周重复。

## 直接复制的实战提示词

请每周自动对【项目名称/项目文件夹】进行一次巡检，并与上一期结果比较。重点检查：①补充尽调清单/任务表中已完成、部分完成、未完成事项；②法律意见书、尽调报告、问询回复中的【待核验/待补充/待客户确认】及批注；③本周新增材料是否同步到对应成果；④核心文件是否存在版本冲突；⑤新增变化是否同步到相关文件；⑥未来7天、14天、30天的重要期限；⑦连续多期未解决的问题。最终生成简洁的【项目周巡检报告】，只列本周变化、异常、未完成事项、临近期限、下周优先任务和【需要律师确认】事项，不得自行修改或删除项目文件。

## 最后记住一句话

长期项目最怕的不是事情多，而是：**不知道还有什么没做。**
