# AI实战17｜客户补资料回来后，不要重做报告：只更新受影响的章节

客户第二轮补资料回来后，很多人会让AI“重新生成一份报告”。这会把已经人工确认的内容重新改乱。正确思路是先判断新增材料影响哪些章节，只改受影响部分。

## 一、先归档再更新

新增材料先按原尽调清单编号归档，并记录新旧版本关系，再判断它影响哪些事实、待核验事项和报告章节。

## 二、只解决有材料依据的问题

原来标记【待补充】的事项，只有新材料确实足以解决时才能删除标记。新材料也可能带来新的风险或矛盾，不能只做“清空待办”。

## 三、保留已确认内容

本轮应从律师已经确认的V1或V2继续修改，未受影响章节原则上不重写。

## 四、每轮留下更新说明

列明本轮新增材料、已解决问题、新增问题、仍待核验事项和修改章节，方便下轮继续。

## 直接复制的实战提示词

请根据【上一版尽调报告】和【本轮新增材料目录】进行增量更新。先将新增材料对应到原尽调清单序号，识别受影响章节和待核验事项；只修改受影响内容，不得重写已由律师确认且无新材料影响的章节。删除原【待核验/待补充】标记必须有新增材料依据，同时允许新增风险和新待办。另存为新版本，并生成【本轮更新说明.md】，列明新增材料、已解决问题、新增问题、仍待核验事项及修改位置。

## 最后记住一句话

补资料回来以后，不是“重做报告”，而是：**只更新被新事实影响的地方。**
