# AI实战18｜尽调报告写完别急着发：先让Agent做一次全文交叉核对

尽调报告完成以后，最容易出现的不是某一章完全写错，而是章节之间、表格与正文之间、旧项目与新项目之间出现不一致。正式发出前，最好做两轮交叉核对。

## 一、第一轮由起草Agent自检

检查主体、股权、历史沿革、金额、日期、表格与正文、章节结论、交叉引用、旧项目残留、未处理批注和无依据的强结论。

## 二、第二轮换一个独立Agent

把尽调报告和原始尽调大纲/清单交给没有参与主要起草的Agent，先检查是否漏掉清单要求，再从事实和逻辑上寻找矛盾。必要时读取关键底稿验证。

## 三、先出问题表，不要直接改

独立Agent只列出问题位置、原因、可能影响和建议核查依据。不同Agent意见冲突时回到原始材料，由律师判断。

## 直接复制的实战提示词

请作为未参与本报告主要起草的独立复核Agent，审阅【尽调报告】并与【原尽调清单/大纲】对照。本阶段不要直接修改。先检查清单要求是否有遗漏，再核对主体、股权、日期、金额、表格与正文、章节结论、交叉引用、旧项目残留、未处理标记和无材料支撑的结论；必要时查看【关键底稿目录】。最终生成【全文交叉核对问题表.xlsx】，列明问题位置、问题类型、判断依据和建议核查材料，争议事项标记【律师确认】。

## 最后记住一句话

重要报告最好经过：**起草Agent自检 + 另一个Agent独立复核 + 律师最终判断。**
