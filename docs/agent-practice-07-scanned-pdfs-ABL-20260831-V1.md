# AI实战07｜一堆扫描PDF怎么处理？让Agent先识别，再整理，再提取

扫描件、图片PDF、拍照证据最麻烦的地方，是内容不能稳定检索。处理这类材料最好固定成三步：先识别，再整理，再提取。

## 一、先判断哪些文件需要识别

不要对所有PDF都盲目OCR。先区分可直接读取的文本PDF与扫描页，对真正无法提取文本的页面再做识别。

## 二、识别后保留来源定位

提取任何事实时保留原文件名、页码，模糊字、缺页、印章遮挡和识别不确定处都标记出来，不能把猜测后的文字当原文。

## 三、再做结构化整理

完成识别后，再提取合同主体、日期、金额、证据事项等需要字段，并生成材料清单。识别文本只是中间层，不是最终成果。

## 直接复制的实战提示词

请处理【扫描PDF/图片资料目录】。先区分可直接读取文件与真正需要识别的扫描页，仅对必要页面进行文字识别；提取内容时始终保留原文件名和页码。对模糊、缺页、无法确认的文字标记【识别不确定】，不得猜写。识别完成后按【目标字段】结构化提取，并生成【材料清单.xlsx/整理结果.md】及异常页清单。

## 最后记住一句话

扫描件处理最重要的不是识别率，而是：**不确定的地方必须让律师看得见。**
