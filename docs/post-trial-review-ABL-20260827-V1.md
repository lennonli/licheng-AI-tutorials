# 庭后复盘与裁判文书深读教程

> 诉讼实战系列（四）｜适用：AI智能体（OCR 转写 + 类案检索 + 文书结构化）｜2026-08-27
> 用途：庭审结束后到收到判决书之后——复盘得失、深读裁判逻辑、决策是否上诉。

## 一、它能解决什么问题

三个高频场景：① 庭审笔录/录音一堆原始材料，没人整理成"下一步动作"；② 拿到判决书只看结果不拆逻辑，输了不知道输在哪；③ 上诉与否纠结时缺数据支撑。本教程把这三步流程化。

## 二、输入材料

- 庭审材料：【庭审录音/录像、庭审笔录、我方庭审提纲、对方当庭提交材料】
- 裁判文书：【判决书/裁定书路径】（扫描件可 OCR）
- 本所其他项目的《庭审复盘报告》《上诉风险评估》模板（如有）：【路径】
- 上诉决策相关：一审争议焦点清单、我方预期（可口头描述）

## 三、AI智能体能力配置

| 环节 | 用什么 |
| --- | --- |
| 录音/录像整理 | 本地转写工具输出草稿 → AI 按角色整理（涉密材料不出本机） |
| 笔录扫描件 OCR | 本地 OCR（如 ocrmac） |
| 文书结构化拆解 | 主对话直接处理（结构化任务） |
| 二审改判点检索 | 类案检索子代理 → 元典/北大法宝（同案由+同一审诉求的上诉案件样本） |
| 法条核验 | 法规核验子代理 → 北大法宝 MCP 逐字核验 |
| 复盘报告产出 | Word 文档生成能力 + 模板复用 |

## 四、标准工作流与提示词模板

### 第一步：庭审实录结构化

```text
读取【庭审转写/笔录】，输出结构化实录：
1. 按庭审阶段（法庭调查—举证质证—法庭辩论—最后陈述）分节；
2. 对方每一项质证意见、抗辩观点单独编号提取；
3. 法官全部发问按对象归类（问我方/问对方/问证人），标注我方当场回答与未答部分；
4. 我方当庭表达与庭审提纲的偏离点清单；
5. 当庭未查明、法官释明将另行处理的事项。
原始材料没有的内容不得补充。
```

### 第二步：庭审复盘（交付物一）

```text
基于结构化实录，输出《庭审复盘报告》（Word，如有其他项目更优模板则以模板为基准）：
1. 争议焦点实际聚焦与庭前预判的差异表；
2. 我方表现评估：回答到位/欠佳/失误三档逐项列（附实录原文位置）；
3. 对方新观点与突袭证据清单——哪些需要庭后代理词补充回应；
4. 补强行动清单：代理词要点、补充证据申请、调查取证申请（各附截止时点提示，可建定时任务）。
```

### 第三步：裁判文书深读

```text
读取【判决书】，输出拆解报告：
1. 结构化提取：本院查明事实清单（逐项编号）、本院认为部分的说理链条（前提→依据→结论）、裁判主文；
2. 证据认定表：每份证据的采信结论与法院理由，对照我方举证预期找差异；
3. 隐含信号：法院未回应的诉请/抗辩（可能构成程序或说理瑕疵）；
4. 文书引用的全部法条条文号清单——逐条经北大法宝核对是否引用准确、是否现行有效。
```

### 第四步：上诉决策评估（交付物二）

```text
就"是否上诉"输出量化评估：
1. 检索同一审级、同案由的上诉案件样本（【意向二审法院及其辖区】，近【3】年）：
   改判/维持的大致分布、改判案件的改判理由类型；
2. 对照本案：一审判决的说理弱点是否落入常见改判理由类型，逐项映射；
3. 上诉成本与周期预估：诉讼费、新证据可行性、执行进展影响；
4. 结论分档：建议上诉/可上诉但把握有限/建议服判，各附理由与条件；
5. 样本案号清单与【待核验】事项单列。
最终决策由主办律师作出。
```

## 五、模板复用原则

复盘报告、上诉状等文书：**优先使用律师提供的其他项目更优模板**，AI 做事实填充与结构调整（先长后短替换、零残留质检）；上诉状起草另见系列（一）之文书方法。

## 六、红线

1. 转写与 OCR 有错字风险，关键表述必须回听/回看原文核对；
2. "改判率"类统计必须披露样本范围与局限，禁止伪精确；
3. 判决书引用法条的核对结果只用于内部评估，对外引用以官方文本为准；
4. 上诉期（判决送达之日起15日）盯紧——用定时任务设"上诉期届满前7日/3日"两级提醒。
