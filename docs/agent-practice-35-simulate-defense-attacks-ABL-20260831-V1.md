# AI实战35｜起诉前先站到对方一边：让Agent模拟“质量问题”答辩和攻击路径

准备起诉前，再做一次对抗性检查：把全部材料交给Agent，让它暂时站到买方律师的立场，模拟“质量问题”答辩和攻击路径。目的不是预测对方每句话，而是提前暴露我方最危险的弱点。

## 一、先让Agent重讲一遍对方的案件故事

卖方眼里是“交货后不付款”，买方可能把它讲成“卖方交付不合格产品，因此付款条件未成就并产生损失”。同一组事实可能形成完全不同的诉讼叙事。

## 二、重点推演质量纠纷的攻击线

质量标准是什么、何时提出异议、卖方是否曾“承认”问题、对方用什么证明缺陷、缺陷由谁造成、是否有权拒付全部货款、是否主张减价/抵销/反诉。

## 三、专门攻击我方证据

送货单只能证明交付还是也能证明验收？发票能否证明欠款？售后聊天会不会反过来证明卖方认可质量异常？

## 四、挑出最危险的三个点

不要平均处理几十个可能抗辩，最后明确如果代理买方，最希望抓住卖方哪三个弱点，并据此补证或调整起诉策略。

## 直接复制的实战提示词

请站在【买方/被告】代理律师立场，基于【全部案件材料】模拟本案可能的答辩和攻击路径。本案为卖方已交货、买方以货物质量问题拖欠货款。请重点围绕质量标准、异议提出时间、验收、卖方是否曾承认质量问题、缺陷证据及成因、拒付货款依据、损失抵销和可能反诉逐项攻击我方事实与证据。区分【材料中已有的对方观点】与【推测的潜在抗辩】，不得虚构事实。最终生成【对方答辩与攻击路径分析表.xlsx/报告.docx】，并列出最危险的三个风险点和补证建议。

## 最后记住一句话

起诉前不只要想“我为什么能赢”，还要问：**如果我是对方律师，我会从哪里打我自己？**
