# AI实战09｜开完会别自己整理：让Agent直接生成纪要和待办清单

开完会后最耗时间的往往不是会议本身，而是整理纪要、决定和待办。Agent可以在会议记录、录音转写或笔记基础上直接形成可执行结果。

## 一、区分讨论、决定和待办

“有人提议”不等于“会议已决定”。纪要必须明确哪些只是讨论意见，哪些已经确认，哪些形成具体行动。

## 二、待办要有责任人和期限

不要只写“跟进材料”。应尽量整理为事项、责任人、截止时间、依赖材料和当前状态；会议中没有明确责任人或日期的，不要自行编。

## 三、把未决问题单独留下

争议未解决、需要客户确认、需要进一步检索的问题，应进入“待确认事项”，防止会议结束后消失。

## 直接复制的实战提示词

请根据【会议记录/录音转写/笔记】生成【会议纪要.docx】和【待办清单.xlsx】。请严格区分【讨论意见】【已确认决定】【后续待办】，不要把建议写成最终决定。待办尽量列明事项、责任人、截止时间和依赖材料；原记录未明确的信息标记【待确认】。另列出未决问题和需要律师/客户进一步决定的事项。

## 最后记住一句话

会议纪要最有价值的不是“记得完整”，而是：**会后谁做什么，一眼就能看到。**
