# AI实战50｜每天早上，让Agent自动生成一份“律师工作晨报”

日历、邮件、项目文件、法律资讯、监控提醒分别看都不复杂，真正耗时间的是每天早上重新把这些信息拼成“今天应该做什么”。律师工作晨报就是把多个信息源自动汇总成一份当天可执行的工作入口。

## 一、晨报回答“今天怎么工作”

它不是新闻简报，而是把日程、重要邮件、项目变化、监控触发、法律动态和期限转成今天需要行动的事项。

## 二、日程不只列时间，还要列准备事项

例如下午开庭，就提醒庭审提纲、证据原件和授权材料；客户会前要完成协议版本比对。

## 三、邮件只筛需要行动的

新增客户材料、法院通知、对方律师来函、项目组重要邮件进入晨报，普通未读邮件不用全部搬进来。

## 四、项目和监控只报变化

昨天补了什么材料、哪个文件没同步、哪项监控触发；没有变化就不重复。

## 五、统一扫描期限

未来7天、14天、30天的举证、开庭、问询、许可证、合同通知期等集中提示。

## 六、最后只给3—5个今日优先事项

根据期限、重要程度和是否阻塞其他工作排序；另设【需要律师确认】栏目，把必须由律师决定的问题集中出来。

## 七、解决的问题第二天消失

晨报不能越积越长，只保留新出现和仍未解决的事项。不同业务律师可以配置完全不同的晨报重点。

## 直接复制的实战提示词

请每天在【指定时间】自动生成【律师工作晨报】。综合读取【日历】【重要邮件】【当前项目清单/项目文件】【任务与期限】【每日法律资讯结果】【条件监控结果】，只整理与当天工作直接相关的新信息和未解决事项。晨报包括：①今日会议/开庭及准备事项；②当天需处理的重要邮件和新增材料；③项目新变化和异常；④触发的监控提醒；⑤与当前项目直接相关的重要法律监管动态；⑥未来7天、14天、30天的重要期限；⑦今日建议优先处理的3—5项工作；⑧需要律师本人确认和决策的事项。已经解决、无变化或无需行动的信息不要重复出现，信息不足标记【待确认】，不得自行作出专业法律决定。

## 最后记住一句话

律师每天早上真正需要快速知道的只有四件事：**今天有什么、什么最急、什么变了、什么必须由我决定。**
