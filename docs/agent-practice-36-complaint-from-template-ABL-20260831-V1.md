# AI实战36｜起诉状不要从零写：把历史优质模板交给Agent直接改成新案件

前面的案件研究、证据整理和对方攻击路径做完后，才进入起诉状起草。最稳妥的方式不是让AI从零写，而是提供一份自己以前认可的同类起诉状模板，让Agent延续律师原有的结构、表达和Word格式。

## 一、模板只学写法，不继承旧案事实

历史模板可以提供诉讼请求表述、事实与理由结构、标题层级和文风；旧主体、法院、案号、金额、日期、法律结论必须全部清除。

## 二、同时提供当前案件成果

当前案件材料、案件分析报告、事实—证据对应表、对方攻击路径一起输入。这样Agent写的是“有证据支撑的起诉状”，不是把客户故事润色一下。

## 三、诉讼请求先单独核

货款、利息/违约金、律师费等都要根据合同和实际履行逐项确认，不得因为历史模板里有就自动加。

## 四、质量争议不要无视

如果材料已经显示买方曾提出质量异议，不能写成“从未提出”。具体披露到什么程度由律师基于诉讼策略决定。

## 五、起草后做证据反查和模板残留检查

每个关键事实回到对应证据，同时扫描旧公司、旧金额、旧法院和旧日期。

## 直接复制的实战提示词

请根据【当前案件材料】【案件分析报告】【事实—证据对应表】【对方答辩与攻击路径】起草本案民事起诉状。本案为卖方追索货款的买卖合同质量纠纷。请以【历史优质起诉状模板】作为结构、格式和表达风格参考，延续其诉请表述和事实组织方式，但不得沿用旧案主体、事实、金额、日期或结论。所有关键事实必须能对应当前证据，无法确认的标记【待核验】。完成后核对诉请金额、关键时间、交付付款、质量异议及证据对应，并另存【本案起诉状_初稿.docx】，不得覆盖模板。

## 最后记住一句话

起诉状不是让AI重新学一次怎么写，而是：**让它沿着律师已经成熟的写法，处理这个新案件。**
