# 诉讼证据整理与证据目录制作教程

> 诉讼实战系列（六）｜适用：AI智能体（本地 OCR + 网核留痕 + docx）｜2026-08-27
> 用途：把一堆扫描件、照片、聊天记录变成结构规范、证明目的清晰的证据体系。

## 一、它能解决什么问题

开庭前证据工作的三个痛点：**材料杂乱没分类、关键信息没提取、证明目的与事实主张对不上**。本教程把"清点—提取—编组—成目录—找缺口"流程化，产出可直接提交法庭的证据目录。

## 二、输入材料

- 原始证据材料目录：【路径】（扫描件 PDF、照片、微信记录导出、票据等）
- 案件事实主张清单：【我方主张的每项事实，可口头描述】
- 对方已提交证据（如为二审/质证阶段）：【路径】
- 本所其他项目的《证据目录》模板：【路径】（优先使用）

## 三、AI智能体能力配置

| 环节 | 用什么 |
| --- | --- |
| 扫描件 OCR | 本地 OCR 工具（如 ocrmac，本地运行，保密材料不出机）；低质量盖章件换第二引擎交叉核验 |
| 网页类证据固定 | 网络核查留痕技能（截图/存档 PDF 留痕，记录取证时间） |
| 主体信息补全 | 企业信息库（企查查/天眼查）：营业执照信息、登记日期核对 |
| 证据目录成稿 | Word 文档生成能力 + 模板复用原则 |
| 材料清点比对 | 主对话遍历目录（生成清点表） |

## 四、标准工作流与提示词模板

### 第一步：材料清点与预分类

```text
遍历【原始证据材料目录】，输出清点表：
文件名、格式、页数、OCR 预览首行（判断内容类型）。
先按五大证据组预分类：
①主体资格类 ②法律关系类（合同/协议）③履行类（交付/付款/验收）
④违约与催告类 ⑤损失类。
无法判断的列"待人工分类"，不要硬分。
```

### 第二步：OCR 提取与关键信息登记

```text
对全部材料执行本地 OCR，输出《证据要素登记表》，每份材料一行：
证据编号、形成时间、涉及主体、金额（如有）、关键内容摘要（50字内）、
对应证据组、原件/复印件、来源（当事人提供/自行收集/申请调取）。
要求：
1. 金额、日期、主体名称三类信息必须回看原图逐字核对，OCR 与图不一致的以图为准并标注；
2. 多页合同登记关键条款页码（签署页、金额条款、管辖条款）。
```

### 第三步：证明目的倒推编组（核心）

```text
以【事实主张清单】为纲，反向编排证据组：
每项事实主张 → 支撑它的证据编号序列 → 每份证据的证明目的（一句话，具体到待证事实）。
检查：
1. 没有证据支撑的主张 → 列入"待补证据清单"，并给出取证路径建议
   （律师调查令/申请法院调取/公证/当事人补充提供）；
2. 与任何主张无关的材料 → 列"备用材料"，不进正卷；
3. 同一证明目的证据重复的，排序规则：原件优先、形成时间近优先。
```

### 第四步：证据目录成稿（模板复用）

```text
生成《证据目录》（Word）：
【优先】以我提供的其他项目模板【路径】为基准，仅填充：
证据编号、证据名称、证据来源、证明对象（内容摘要）、证明目的、页码、原件/复印件。
保留模板的表格结构与列设置；无模板再按律所格式新建。
同步输出：证据册装订页码对照表（每份证据在合卷中的起止页）。
```

### 第五步：双方证据比对（二审/复杂案件加做）

```text
对照【对方证据清单】，输出比对表：
对方证据编号—其证明目的—我方对其的初步质证方向（三性预判）—
我方反证证据编号。
为我方需要补充的反证单独列清单。
```

## 五、模板复用原则

证据目录、要素登记表等：**优先用律师提供的其他项目更优模板**，AI 只填要素、调列宽，不动表格结构；新起草部分在修改说明中标注。

## 六、红线

1. OCR 是辅助，**金额、日期、名称必须回原图核对**（防幻觉红线）；
2. 微信/QQ 记录须提示当事人保留原始载体（手机原件），导出件注明提取方式；
3. 证明目的措辞与证据内容严格对应，不夸大（"证明双方存在买卖合同关系"而非"证明对方违约"——除非该证据直接指向）；
4. 涉密材料全程本地处理，不上传云端解析服务。
