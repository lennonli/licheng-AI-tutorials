# AI实战24｜法律文件里的法条别靠AI记：让Agent逐条核验是否最新有效

AI最容易在法律文件里“记住一个大概正确的法条”。正式文件不能接受这种误差。凡是涉及法条、司法解释、部门规章和监管规则，最好在提交前让Agent做一次逐条有效性核验。

## 一、先把所有引用抽出来

扫描报告、合同、备忘录、起诉状或代理词，把法律文件名称、条号、引用内容和所在位置列成表。

## 二、优先专业法规库，失败就回官方来源

可以先用法规数据库MCP核验标题、效力状态、最新版本和条文；MCP无结果或失败时，自动退回国家法律法规数据库、全国人大、中国政府网、最高法、最高检或主管部门官网。

## 三、有效不等于适用

一条规定现行有效，也要检查是否适用于当前主体、行为、地域和时间。历史事实还要判断当时有效的是哪个版本。

## 四、先报告问题，不要悄悄改

列明原引用、现行规则、问题和建议，再由律师决定如何改正文。

## 直接复制的实战提示词

请对【法律文件路径】中的全部法律法规、司法解释、规章和规范性文件引用进行逐条核验。先提取“文件位置—现引用—条号—引用内容”，优先通过【法规数据库MCP】核验效力状态、最新版本和适用性；MCP不可用或无结果时自动使用相应官方来源。请区分“现行有效”与“适用于本案”，历史事项还需核对当时版本。先生成【法条有效性核验表.xlsx】，不要直接修改原文件。

## 最后记住一句话

法条不是“模型记得差不多”就能用。**正式法律文件里的每一条依据，都应该能回到最新、有效、适用的原文。**
