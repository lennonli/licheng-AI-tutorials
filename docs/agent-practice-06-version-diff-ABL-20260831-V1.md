# AI实战06｜两份文件到底改了什么？让Agent直接做版本比对

合同、报告、问询回复更新几轮以后，人工逐页找差异很费时间。Agent很适合做“版本之间到底改了什么”的第一轮比对。

## 一、不要只比较文字

除了新增、删除和改写，还要识别金额、比例、日期、主体、责任、期限、条件等实质变化。一个“应”改成“可”，可能比整段新增文字更重要。

## 二、区分编辑性和实质性变化

错别字、格式、措辞优化可以归为编辑性变化；权利义务、事实数据、风险结论、承诺范围变化则单独列为实质变化。

## 三、把变化对应到影响

法律文件版本比较的价值不是红线，而是告诉律师：这一改动可能影响哪项权利义务、哪段结论、哪份关联文件。

## 直接复制的实战提示词

请比较【旧版本文件】与【新版本文件】，逐项识别新增、删除和修改内容。除文字变化外，重点核对主体、日期、金额、比例、期限、权利义务、责任、条件和法律结论。请区分【编辑性变化】与【实质性变化】，对实质变化说明可能影响，并生成【版本差异清单.xlsx/比较报告.docx】；不要自行判断哪个版本正确，存在冲突时标记【待确认】。

## 最后记住一句话

版本比对不是找“哪里不一样”，而是找：**哪些不一样会产生后果。**
