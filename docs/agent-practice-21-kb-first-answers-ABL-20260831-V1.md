# AI实战21｜别只靠模型记忆：让Agent先查知识库，再回答专业问题

专业问题如果只靠模型记忆，最危险的不是“不会答”，而是答得像真的。更稳妥的方式是：先查自己的知识库、案例库或MCP，再基于真实材料回答。

## 一、先检索，不要先下结论

例如要研究“劳务派遣超比例”的IPO审核案例，应先在内部知识库中用核心词和同义词检索，再打开相关原文，而不是先让模型凭经验总结。

## 二、检索后必须读原文

知识库返回的摘要只是入口。Agent应继续读取问询、回复和律师意见，提取公司、板块、事实背景、监管关注、整改方式和论证路径。

## 三、案例要比较，不要只罗列

真正有价值的是比较不同案例事实为什么不同、监管关注为什么不同、哪些论证是建立在特定事实基础上。

## 四、找不到也要如实说

“知识库未找到”只代表当前库里没有命中，不等于现实中不存在。必要时再扩展到外部专业数据库或官方来源。

## 直接复制的实战提示词

请先通过【知识库/MCP名称】检索【专业问题】，不要先凭模型记忆作答。请同时使用核心关键词、同义词和监管常见表述，打开命中的原始材料并逐案提取【公司/板块/事实背景/问询要点/回复口径/律师核查与结论】。请比较案例差异后再形成结论，所有结论保留来源；知识库未找到时明确说明，并提出需要进一步外部检索的方向。

## 最后记住一句话

专业AI最重要的习惯之一是：**先查资料，再说结论。**
