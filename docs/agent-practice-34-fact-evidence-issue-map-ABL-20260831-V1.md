# AI实战34｜案件研究完成后，让Agent把证据整理成“事实—证据—争议焦点”对应表

案件分析完成后，下一步不要急着起草文书，而是把“我们想证明的事实”与手里的证据真正对应起来。诉讼不是只要法律上有道理，还要证明得出来。

## 一、先盘点全部证据

识别每份材料的名称、形成时间、主体、主要内容、完整性、重复、版本、扫描质量和是否缺页。

## 二、从争议焦点反推待证明事实

例如合同成立、交付、付款、质量异议、验收、催款、继续使用等，再逐项找对应证据。

## 三、判断证明力度和缺口

可以简单分强、中、弱/待核验。只有客户陈述没有证据的事实明确标记【缺乏证据】；证据之间日期、金额或内容冲突则单独列出。

## 四、同时找对我方不利的证据

例如卖方曾承认“产品有问题”的聊天、同意延期付款的沟通，都可能成为对方攻击点。越早发现越好。

## 五、形成三份成果

证据目录、事实—证据—争议焦点对应表、证据缺口及补证清单。

## 直接复制的实战提示词

请阅读【全部案件证据材料】及【案件分析报告】，先盘点全部证据并识别重复、缺页、版本异常和无法读取项。随后以核心争议焦点和我方拟主张事实为主线，生成【事实—证据—争议焦点对应表.xlsx】，列明待证明事实、对应证据、证据主要内容、初步证明力度、存在问题和对方可能抗辩。只有客户陈述但无证据支持的事实标记【缺乏证据】，证据冲突单独列明。另生成【证据缺口及补证清单.xlsx】和【证据目录初稿.docx】。

## 最后记住一句话

起草诉讼文书前，先问一句：**准备写进去的每个关键事实，手里到底有什么证据能证明？**
