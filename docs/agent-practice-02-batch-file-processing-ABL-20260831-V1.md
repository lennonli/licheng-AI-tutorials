# AI实战02｜一次处理几十个文件：不要再一份一份上传给AI

几十份合同、底稿、证据或客户材料，如果仍然一份一份上传、逐个提问，AI带来的效率提升会非常有限。Agent真正适合的是把“文件夹”作为工作单位。

## 一、先盘点，再批量处理

第一步不要急着总结。先让Agent列出文件总数、类型、目录结构、重复文件、无法读取文件和可能的版本关系。只有先知道“有什么”，后面的批量处理才不会漏。

## 二、建立统一提取规则

例如几十份合同时统一提取主体、日期、金额、期限、违约、争议解决；几十份尽调材料统一提取文件名称、所属清单序号、形成时间、关键内容。统一字段比逐份自由总结更容易比较。

## 三、异常项单独拎出来

批量任务最怕“看起来都处理完了，但有三份其实没读到”。所以必须单独输出无法读取、字段缺失、内容冲突、重复版本和疑似异常文件，并核对处理数量与原始文件总数。

## 直接复制的实战提示词

请批量处理【文件夹路径】内全部文件。先生成文件盘点表，统计文件总数、类型、重复/版本关系及无法读取项；再按照【统一字段】逐份读取实际内容并提取，不得只依据文件名判断。最终生成【汇总表.xlsx/报告.md】，并单独列出异常文件、缺失字段和需人工确认事项；处理完成后核对“成功处理+异常+无法读取”数量与原始文件总数是否一致。

## 最后记住一句话

批量处理的第一原则不是“快”，而是：**一份不漏，异常可见。**
