# AI实战27｜IPO问询来了，先让Agent把整份问询函拆成核查任务清单

IPO问询函一来，最容易犯的错误是马上起草回复。真正高效的做法是先把整份问询拆成可执行的核查任务，确认每个小问需要谁提供什么。

## 一、把大问题拆到最小问

一段问询里常包含“说明A、结合B分析C，并请律师发表明确意见”。Agent应逐句拆开，确保没有一个小要求被埋在长句里。

## 二、按任务类型分工

每个小问可以归为事实核查、补充资料、客户说明、法律检索、证券案例检索、公司回复、律师核查、其他中介配合等。

## 三、区分公司说明和律师意见

监管常常要求发行人说明，同时要求中介发表明确意见。两部分的事实基础和写法不同，任务表里应分开。

## 四、先形成任务清单，再写回复

项目组确认任务、补资料、完成检索后，再逐题起草。

## 直接复制的实战提示词

请阅读【IPO审核问询函】及【当前申报文件/项目材料】，逐题拆解问询要求。每个大题必须拆到最小子问题，包括“说明、结合、核查、发表明确意见”等所有要求，并为每个子问题列明【需要核查的事实】【补充材料】【客户说明】【法律/证券案例检索】【公司回复任务】【律师核查与意见】【其他中介配合】。最终生成【问询核查任务清单.xlsx】，本阶段不要直接起草问询回复。

## 最后记住一句话

问询回复最怕“写了很多，却漏答一个小问”。所以第一步不是写，而是：**把监管的问题彻底拆完。**
