# AI实战20｜尽调发现问题后，让Agent直接转成交易文件修改建议

尽调发现问题以后，不能只停留在“有风险”。交易律师真正要做的是把风险转成合同里的保护机制。Agent很适合先做风险到条款的映射。

## 一、先看现有交易文件有没有覆盖

把重大问题清单和现有SPA、投资协议等一起交给Agent，先找相关条款，避免重复增加已经存在的保护。

## 二、把风险转成具体机制

常见机制包括交割前提、陈述与保证、承诺、专项赔偿、价格调整、留置/托管、付款条件等。一个风险可能需要多层保护。

## 三、明确交易立场

买方、卖方、投资人、目标公司立场不同。提示词里必须先说代表谁，否则Agent容易给出看似全面但互相冲突的条款建议。

## 四、先出方案表，再改协议

先让律师确认保护方式，再在交易文件里落条款，避免Agent直接大改整份协议。

## 直接复制的实战提示词

请根据【重大问题清单】和【当前交易文件】从【买方/卖方/投资人等我方立场】分析每项尽调风险。先检查现有协议是否已有对应保护，再生成【风险—交易机制建议表.xlsx】，列明风险事实、可能影响、现有条款、建议采用的交割前提/陈述保证/承诺/专项赔偿/价格或付款机制及修改方向。本阶段不要直接修改协议，待律师确认方案后再按指定条款增量修改。

## 最后记住一句话

尽调真正进入交易价值的那一步，是：**把发现的问题变成可以写进交易文件的保护。**
