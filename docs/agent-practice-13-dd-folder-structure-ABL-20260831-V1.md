# AI实战13｜别手工建尽调目录：让Agent按尽调清单序号直接生成文件夹

尽调目录本身已经有一套编号体系，就不要再让AI按照“公司、股权、资产、合同”等自己的理解重新设计文件夹。最稳定的做法是：让文件夹严格镜像尽调清单。

## 一、尽调清单序号就是文件夹序号

一级序号建立一级目录，二级序号放在对应一级目录下，三级继续向下。例如“1 公司基本情况”“1.1 营业执照”。文件夹可以命名为“1-公司基本情况”“1.1-营业执照”。

## 二、清单没有下级编号，就不要让Agent发明

如果清单只有“5.2 知识产权”而没有5.2.1、5.2.2，就不要再自动拆成商标、专利、软件著作权文件夹。额外分类会让资料目录和清单失去一一对应。

## 三、后续所有工作都沿用同一编号

客户补资料、材料归档、报告引用、补充清单，都继续用这套序号。这样“尽调清单序号=文件夹序号=资料分类序号”。

## 直接复制的实战提示词

请读取【尽调清单文件】并在【目标目录】按清单现有编号和层级生成尽调文件夹。一级序号建立一级目录，二级及更低层级严格放在对应父目录下，统一命名为“序号-事项名称”。不得根据内容自行增加清单中不存在的下级文件夹，也不得调整原清单编号。完成后生成【目录树.md】供我核对。

## 最后记住一句话

尽调目录最重要的不是分类多精细，而是：**清单怎么编号，文件夹就怎么编号。**
