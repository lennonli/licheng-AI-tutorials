# AI实战44｜决定上诉后，让Agent围绕“能改变结果的点”起草上诉状

只有在判决分析和上诉评估做完、律师真正决定上诉以后，才进入上诉状起草。二审文书最怕把一审代理词重新写一遍；上诉状应围绕“一审具体错在哪里、为什么会影响结果、二审应怎样改”展开。

## 一、先明确想改变什么结果

是撤销某项货款扣减、提高违约金、支持质量损失还是全部改判。没有明确目标，Agent容易把所有不满都写进去。

## 二、每个上诉请求对应一个具体错误

可以分事实认定、证据采信、法律适用和程序问题。上诉理由必须直接对应判决原文和最终请求。

## 三、质量纠纷重点抓证明范围

例如检测只覆盖部分样品，却被用于认定全部货物不合格；维修行为被扩大解释为承认全部责任；损失金额缺乏实际凭证却被整体采纳。

## 四、不要强行否定所有不利事实

即使部分产品确有异常，也可以争论其范围、原因和法律后果，而不是写成“从不存在任何质量问题”。

## 五、先做上诉框架并筛强弱

核心理由写透，辅助理由适量，弱理由可以删。必要时针对最终保留的上诉点再做精确类案检索。

## 六、模板和二审法官复核

以历史优质上诉状延续风格，起草后再换一个Agent模拟二审法官，检查哪些只是重复一审意见、哪些真正可能影响结果。

## 直接复制的实战提示词

请根据【一审判决】【判决分析及上诉评估报告】【一审诉辩文件】【双方证据及质证】【庭审笔录】【代理词】协助起草上诉状。先围绕律师已确认的【拟改变判决结果】和【核心上诉点】，生成“上诉请求—一审认定—存在问题—证据/法律依据—拟请求二审处理方式”框架；必要时通过【法规及案例数据库MCP】针对最终上诉点补充检索。框架经律师确认后，以【历史优质上诉状模板】作为结构和表达参考起草【民事上诉状_初稿.docx】，不得简单重复一审代理词或继承旧案事实，二审新证据标记【待核验】。

## 最后记住一句话

上诉状不是“再讲一遍我为什么对”，而是：**一审哪一步错了，这一步为什么影响结果。**
