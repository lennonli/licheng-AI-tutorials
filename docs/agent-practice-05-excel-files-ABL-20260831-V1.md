# AI实战05｜让Agent直接处理Excel：不要只让AI给你一张Markdown表格

表格任务如果最后只得到一张Markdown表，很多真实工作仍然要人工重做。客户清单、合同台账、尽调表、财务数据整理，都应该直接让Agent处理真实Excel。

## 一、先理解工作簿结构

先读取所有工作表、表头、公式、隐藏列和已有格式，确认哪些区域可以改、哪些公式必须保留。不要一上来重建整张表。

## 二、让数据真正落入单元格

清洗、去重、合并、分类、计算和补字段都在XLSX里完成。需要计算的尽量用公式，涉及原始数据时保留来源列或原始sheet，便于复核。

## 三、完成后做数据校验

至少检查总行数、重复项、空值、金额合计、公式错误和异常值。批量写入后再随机抽查原始材料，避免结构正确但内容错位。

## 直接复制的实战提示词

请直接处理【Excel文件路径】。先识别工作簿各Sheet、表头、公式和已有格式，再按【任务要求】进行清洗/合并/分类/计算/补充字段。不得破坏原始数据和现有有效公式，必要时保留原始Sheet并另建处理结果Sheet。最终输出【新文件.xlsx】，并校验总行数、重复项、空值、金额合计和公式错误，列出需要人工确认的异常数据。

## 最后记住一句话

Excel工作的目标不是“给我看一张表”，而是：**把真正能继续工作的XLSX交回来。**
