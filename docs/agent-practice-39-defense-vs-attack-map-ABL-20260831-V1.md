# AI实战39｜收到被告答辩状后，让Agent把真实答辩和之前的攻击路径逐项对照

立案后真正收到被告答辩状时，不要重新从头分析。前面已经做过对方攻击路径模拟，现在最有价值的是把“预测”和“真实答辩”逐项对照，快速识别哪些风险兑现、哪些没有出现、哪些是新增争议。

## 一、先把真实答辩拆成最小主张

区分事实主张、法律观点、证据主张和金额主张，例如质量缺陷、及时异议、付款条件未成就、损失抵销、反诉等。

## 二、与起诉前模拟表逐项对应

标记【此前已预测】【此前预测但未提出】【新增争议点】，尤其关注完全没想到的新事实，例如口头降价、退货、迟延交付等。

## 三、对方新证据单独分析

检测报告、质量通知、聊天、维修、下游索赔等要逐份看它真正能证明什么，并找到我方回应证据。

## 四、真实答辩可能改变案件结构

如果对方提出大额质量损失或准备反诉，就要重新评估是否需要鉴定、补技术材料、补检索和调整策略。

## 五、形成案件策略更新

明确哪些判断没变、哪些风险提高、哪些新增问题要补证、下一步优先做什么。

## 直接复制的实战提示词

请阅读【被告答辩状及其证据】，并与【起诉前对方答辩与攻击路径分析】【案件分析报告】【事实—证据对应表】逐项对照。本案为卖方追索货款的买卖合同质量纠纷。先把真实答辩拆分为事实、法律、证据和金额主张，再标记【此前已预测】【预测但未提出】【新增争议点】。对新增事实和质量、验收、维修、损失、抵销证据逐项分析，并列明我方回应证据、补证和补充类案检索需求。最终生成【被告答辩对照及案件策略更新表.xlsx/报告.docx】，不要直接修改既有诉讼文件。

## 最后记住一句话

收到答辩状以后不要只问“对方说了什么”，而要问：**什么是我们预料到的，什么真正改变了案件。**
