 # AI 辅助调解与谈判教程

> 诉讼实战系列（五）｜适用：AI智能体（方案测算 + 角色扮演 + 协议起草）｜2026-08-27
> 用途：诉讼内外和解——利益分析、方案量化、对手模拟、协议成稿一条龙。

## 一、它能解决什么问题

调解谈判最难的三件事：**看不透对方的真实底线、算不清方案的实际损益、谈完落不进严密条款**。本教程用 AI 做利益图谱、量化测算、对手模拟和协议起草，律师专注临场判断。

## 二、输入材料

- 案件材料：【路径】（争议事实、双方主张、证据强弱评估）
- 谈判背景：【对方是谁主谈、其决策习惯、有无第三方压力（如对方也在诉讼中）】
- 我方底线授权：【委托人可接受的最低方案】
- 本所其他项目的《和解协议》《调解协议》模板：【路径】（优先使用）

## 三、AI智能体能力配置

| 环节 | 用什么 |
| --- | --- |
| 利益图谱分析 | 主对话结构化分析 |
| 方案量化测算 | 主对话计算（折现对比、分期测算、担保增益） |
| 对手模拟 | 派生子代理扮演对方决策人/代理律师（同系列一方法） |

| 法条核验 | 法规核验子代理 → 北大法宝 MCP（调解协议司法确认等依据） |

## 四、标准工作流与提示词模板

### 第一步：利益图谱

```text
读取【案件材料】，输出双方利益图谱：
1. 各方陈述立场 vs 可推测真实利益（立场是"要500万"，利益可能是"三个月内回款保现金流"）；
2. 双方 BATNA（谈崩后的最佳替代方案）评估：诉讼胜算、执行回款率、时间成本——引用系列二的评估结论（如有）；
3. 可交易变量清单：金额、付款期数、担保、利息豁免、保密条款、后续合作、诉讼费分担、撤诉时点；
4. 预估的成交区间（ZOPA），注明推演依据。
涉及对方的信息推测标注"推测"，与查明事实区分。
```

### 第二步：方案量化测算（核心）

```text
设计【3】套和解方案并量化对比（输出对比表）：
方案A 一次性折价（如按本金85%当日付清）；
方案B 分期全额（如12期，按季）；
方案C 分期+担保（对方股东/关联公司提供保证或抵押）。
每套方案测算：
1. 名义总额与折现值（折现率用【LPR】）；
2. 违约风险敞口：每期未付时的剩余债权与再次诉讼成本；
3. 对我方的税务与时间成本粗估（标注为估算口径）；
4. 与"继续诉讼到底"的期望值对比（引用胜诉率区间×执行回款率的粗略矩阵，披露局限）。
数字计算过程完整列出备查。
```

### 第三步：对手模拟谈判

```text
你扮演【对方主谈人（其代理律师）】，我方提出【选定方案】。
进行两轮谈判模拟：
第一轮：你对方案的第一反应、砍价策略、情绪化表态；
第二轮：你拿到我方让步【描述】后的升级反应与真实松动信号。
输出：对方"表面立场—可能底线—松动信号识别清单"。
```

### 第四步：谈判弹药准备

```text
输出《谈判要点备忘》（Word，一页纸）：
1. 开场锚定方案与让步阶梯（每步让步换取什么，明确写死）；
2. 对方五种常见回应的应对话术（含引用关键证据/法条的时机）；
3. 红线清单（不可让事项）与授权边界；
4. 谈崩预案：当场如何收场、下一步动作（保全/上诉/施压点）。
```

### 第五步：协议起草（模板复用）

```text
起草【和解协议/调解协议】：
【优先】以我提供的其他项目模板【路径】为基准，仅调整：
当事人与案件事实、付款安排（引用第二步测算的方案要素）、
违约触发条款（加速到期、恢复执行原判/另诉的衔接）、
担保条款（如有）、保密与不贬损条款、税费承担、争议解决。
特别注意：调解协议如需司法确认，核验《人民调解法》及现行司法确认程序的条文后引用；
模板没有的新增条款单独在修改说明中列出理由。
```

## 五、模板复用原则

协议类文书**一律优先用律师提供的更优模板**：AI 只填要素、调口径、补违约衔接条款；模板结构、定义条款、签署页格式不动。新起草部分在修改说明中单独标注。

## 六、红线

1. 底线授权（委托人最低接受方案）**不写入任何给对方看的文件**，模拟对话中也用代号；
2. 量化测算的折现率、税率等口径标注来源，属估算的明示"估算"；
3. 涉及司法确认、担保物权设立的条款，法条逐条北大法宝核验后引用；
4. 谈判让步的最终决定权在委托人和主办律师，AI 备忘仅供参考。
