# AI实战33｜拿到一个新案件后，先让Agent查类案，再做一份诉讼案件分析报告

拿到一个新诉讼案件、了解基本案情后，不建议马上写起诉状。先让Agent围绕争议焦点做系统类案检索，再形成一份案件分析报告。整个诉讼专题以一个买卖合同质量纠纷贯穿：卖方已交货，买方以货物有质量问题为由长期拖欠货款。

## 一、先整理事实，再提炼法律问题

读取合同、订单、送货、付款、聊天、质量异议、售后等材料，形成案件概要和时间线。客户口头说明但暂无证据的事实标记【待证据核实】。

## 二、类案检索要围绕真正争议点

例如质量标准、质量异议期限、验收、付款条件、部分瑕疵是否足以拒付全部货款、损失抵销等。不要只搜“买卖合同纠纷”。

## 三、同时找支持和不支持我方的案件

重点比较法院为什么在不同事实下得出不同结论，找到真正影响裁判结果的事实分界线。

## 四、回到本案分析证据

报告最后要回答我方有利事实、不利事实、证据缺口、对方可能抗辩和初步诉讼策略，而不是做一篇案例综述。

## 直接复制的实战提示词

请先阅读【案件材料/客户说明/已有底稿】，整理本案基本事实、关键时间线、现有证据和待核实事项，并提炼核心争议问题。本案为卖方已交货、买方以质量问题拒付货款的买卖合同纠纷。随后调用【法律案例数据库MCP】开展多轮类案检索，同时查找支持和不支持我方立场的案件，逐案核验案号、法院、审级、日期、关键事实、裁判理由和结果，并比较与本案的相似和差异。结合现行有效法律法规，最终按照通用法律文件格式生成【诉讼案件分析报告.docx】。

## 最后记住一句话

拿到新案件以后，不要先问“起诉状怎么写”，先问：**类似案件法院怎么判，我们的证据又够不够。**
