# AI实战45｜标准化法律文书别每次重写：把旧模板交给Agent，直接生成新案件文件

律师日常还有大量结构固定、事实变量变化的标准化文书：执行申请书、执行异议、财产保全、鉴定申请、调查取证、延期举证、撤诉、变更诉请等。这类文件非常适合“历史成熟模板+新案件材料”直接生成。

## 一、模板负责怎么写，新材料负责写什么

旧模板提供标题、申请事项、事实理由、附件、落款、Word格式和语言习惯；旧案主体、案号、法院、金额、日期、事实和结论都必须清除。

## 二、先从新案件原始材料提取变量

例如执行申请应直接读取生效判决、履行记录和收款信息，提取申请执行人、被执行人、案号、履行期限、未付金额和申请事项。

## 三、不要做机械姓名替换

新案的裁判主文、损失结构、申请事项可能与模板不同。Agent必须理解当前案件后重新起草，而不是把A改成B。

## 四、直接修改Word并另存

保留成熟版式，生成新项目文件，不覆盖模板。

## 五、最后做两轮检查

先扫旧项目残留：旧公司、法院、案号、金额、日期、地址等；再查新文件内部主体、金额、日期和请求是否全文一致。缺材料就标【待确认】。

## 六、逐步建立自己的模板库

常用诉讼、执行、保全和程序申请文书分类保存，以后让Agent先选最匹配模板，再生成新项目文件。

## 直接复制的实战提示词

请根据【当前案件材料】起草【法律文书名称】。先读取【历史优质模板】，仅学习其结构、格式、标题层级、表述习惯和整体文风，再从当前案件的判决、合同、证据等原始材料中提取主体、案号、法院、日期、金额、事实、请求和法律依据。不得机械替换模板，也不得沿用旧项目任何事实或结论；缺少依据的信息标记【待确认】。请直接生成【新项目_法律文书名称_初稿.docx】，不得覆盖模板。完成后分别检查【旧项目残留】和【新文件主体/案号/金额/日期/请求全文一致性】，并列明需律师确认事项。

## 最后记住一句话

大量标准化法律文书没必要每次从空白页开始。**律师过去写好的成熟文件，本身就是最好的AI模板。**
