# AI实战42｜庭审结束后，让Agent根据庭审笔录起草代理词

庭审结束后，代理词不能简单把开庭前案件分析和庭审提纲再抄一遍。此时很多事项已经从“预测”变成“真实发生”，最重要的输入应当是庭审笔录或律师庭审记录。

## 一、先整理庭上真正发生了什么

提取法官实际归纳或重点追问的争议焦点、双方承认事实、实际答辩、质证结果、新观点和法院要求庭后补充的事项。

## 二、重点找对方承认和前后变化

例如书面答辩称全部货物不合格，庭上却承认仅部分产品出现问题；原主张损失300万元，庭上承认多数只是估算。这些变化应进入代理词。

## 三、法官反复问的就是代理词重点

如果法官连续追问验收、检测样品、维修原因、损失支付凭证，代理词就应优先把这些问题讲透。

## 四、围绕庭后真实争议重新收束

不要机械保留开庭前所有争议点。代理词应突出庭审后仍需法院判断的核心问题，以及对方证据真正证明到什么程度。

## 五、先框架再全文

先让Agent形成代理词框架，律师确认后，再以历史优质代理词模板起草；庭审首次出现但无证据的事实不得直接写成确定事实。

## 直接复制的实战提示词

请根据【庭审笔录/律师庭审记录】【起诉状】【被告答辩状】【双方证据及质证意见】【庭审提纲】整理庭后案件情况。本案为卖方追索货款的买卖合同质量纠纷。请先提取法官实际关注的争议焦点、双方庭上承认事实、被告书面答辩与庭审陈述变化、重点发问、质证情况及庭后补充事项，并形成代理词框架；重点分析质量证据实际证明范围、部分质量问题是否足以拒付全部货款、损失及因果关系。框架经律师确认后，以【历史优质代理词模板】起草【代理词_初稿.docx】，庭上首次出现但缺乏证据的事实标记【待核验】。

## 最后记住一句话

代理词真正应该回答的是：**开完庭以后，这个案件现在还剩下哪些问题需要法院判断。**
