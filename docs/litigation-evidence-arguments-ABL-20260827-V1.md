# 举证质证意见与代理词撰写教程

> 诉讼实战系列（八）｜适用：AI智能体（三性分析框架 + 类案口径检索 + 法条核验）｜2026-08-27
> 用途：对方证据的逐份质证、我方举证说明、代理词成稿。

## 一、它能解决什么问题

质证与代理词是"临场发挥重灾区"：**对方证据堆几十份没时间逐份拆、代理观点与证据脱节**。本教程把质证做成逐份分析表、把代理词做成"焦点—论证—证据—法条"四联结构，庭审前就基本成形。

## 二、输入材料

- 对方证据清单及材料：【路径】（含证据目录、证明目的）
- 我方证据体系：系列六的《证据目录》与要素登记表
- 争议焦点预判：【庭前归纳或模拟法庭（系列一）的焦点结论】
- 本所其他项目的《质证意见》《代理词》模板：【路径】（优先使用）

## 三、AI智能体能力配置

| 环节 | 用什么 |
| --- | --- |
| 对方证据通读 | 主对话；扫描件 本地 OCR |
| 质证口径参考 | 元典/北大法宝类案（同类证据的采信与排除口径）+ 类案检索子代理 |
| 法条核验 | 法规核验子代理 → 北大法宝 MCP（证据规定等逐字核验） |
| 文书成稿 | Word 文档生成能力 + 模板复用 |

## 四、标准工作流与提示词模板

### 第一步：对方证据逐份质证表（核心）

```text
读取【对方证据清单及材料】，输出《质证意见表》，每份证据一行：
对方证据编号｜名称｜其证明目的｜我方质证意见（分三栏）：
- 真实性：认可/不认可/无法确认（需核原件的注明"真实性待核原件"）；
- 合法性：取证方式有无瑕疵（严重侵犯权益/违反禁止性方法的才提，不滥提）；
- 关联性：与本案待证事实的关联程度——不相关的说明理由；
- 证明力：即使真实，能否达到其证明目的（孤证/待证事实过远/与在案证据矛盾）。
措辞纪律：把握不足的用"无法确认""不足以证明"，不用绝对化的"伪造""虚假"。
```

### 第二步：我方举证说明与补强

```text
对照对方质证预判（模拟其对我方证据的三性攻击），输出：
1. 我方每份关键证据的"防御说明"：原件情况、来源合法性、与待证事实的链条；
2. 需补强的证据清单：申请证人出庭、调取证据、鉴定/评估的建议（附理由与期限提示）；
3. 证据矛盾点处理：我方证据之间或与陈述的出入，提前给出合理解释口径。
```

### 第三步：代理词框架（核心）

```text
起草【代理词】框架：
【优先】以我提供的其他项目模板【路径】为基准。结构按：
1. 争议焦点归纳（按法庭归纳顺序排列，未开庭的按预判）；
2. 逐焦点论证：论点—在案证据（编号）—法律依据（经核验条文）—类案参考（检索到的裁判口径，附案号）；
3. 结论与请求：明确请求法庭支持的具体内容。
要求：
- 每个论点至少绑定一个证据编号，无证据支撑的观点标注"仅为法律逻辑推演"；
- 法条全部经北大法宝核验后引用；
- 类案引用回库核验案号，检索不到的不写。
```

### 第四步：二审/再审代理词专项

```text
（如为二审）围绕【一审判决书】输出：
1. 原审认定逐项清单：查明事实—说理—结论三段提取；
2. 我方上诉理由与之逐点映射（接系列七上诉状的上诉理由）；
3. 二审代理词重点：新证据说明、原审证据采信错误分析、法律适用错误分析分节展开；
4. 检索二审改判类案支撑（同案由+同类一审瑕疵），样本案号附后。
```

## 五、模板复用原则

质证意见表、代理词：**优先使用律师提供的其他项目更优模板**——表格结构、代理词的分节风格、署名格式均保留，AI 填分析与论证；新起草部分在修改说明中单独标注。

## 六、红线

1. 质证措辞**留有余地**：绝对化定性（"伪造"）无充分依据不用；
2. 代理词中法条与案号"宁可少引、不可错引"——全部回库核验，核验不了就删；
3. AI 生成的论证逻辑须律师逐段审读，防止"看似严密实则偷换前提"；
4. 对方证据中的不利内容不回避、不曲解，不利证据的合理解释口径须与当事人核实。
