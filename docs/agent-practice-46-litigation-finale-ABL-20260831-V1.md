# AI实战46｜诉讼专题最终篇：律师的上限，就是AI的上限

前面的诉讼专题，从类案检索、案件分析、证据整理、起诉答辩、质证、庭审、代理词、判决分析一直做到上诉。AI几乎可以参与每个环节。但这一专题最后必须强调一句：**律师的上限，就是AI的上限。**

## 一、把工作交给AI，不等于把责任交给AI

Agent可以读材料、查案例、算金额、参考模板、形成初稿；但诉请怎么设计、事实该不该写、证据能不能用、风险如何定性、策略怎么选，都不能因为“AI这么写”就接受。AI负责执行，律师负责判断。

## 二、AI越能写，律师越要会审

生成速度越快，错误也可能更快进入文件。未来律师工作会从大量亲自生产，更多转向设计任务、审核成果和作出判断。

## 三、审核重点看五件事

第一，事实是不是真的；第二，证据够不够；第三，从事实到法律结论有没有走太远；第四，文书策略是不是我们真正想要的；第五，有没有漏掉管辖、时效、举证责任、鉴定等真正重要的问题。

## 四、AI可以互审，最后一关仍是律师

起草Agent自检、另一个Agent从对手或法官角度复核都很有价值，但不能代替律师最终审核和确认。

## 五、历史模板也只是模板

模板延续结构、表达和格式，不免除对新事实、新法律和新策略的判断。

## 六、律师真正需要提升的是验收能力

同一个模型，不同律师因为材料组织、问题意识、证据判断和策略能力不同，最后产出会完全不同。

## 直接复制的实战提示词

请对【法律文件/案件成果】进行提交前质量审核，不要只检查文字和格式。重点核对：①主体、日期、金额和关键事实是否与原始材料一致；②重要事实是否有对应证据，客户陈述不得直接作为已证明事实；③法律依据和案例是否准确、有效并适用；④事实到法律结论是否存在逻辑跳跃；⑤诉讼请求、答辩观点或代理意见是否符合既定案件策略；⑥是否遗漏重要争议、程序问题或不利事实；⑦是否存在历史模板残留。请先生成【提交前质量审核清单】，列明问题、位置、依据和建议，不要自行替律师作最终判断。全部修改完成后仍须由律师最终审核确认后方可提交。

## 最后记住一句话

整个诉讼专题真正需要留下的一句话是：

**律师的上限，就是AI的上限。**

AI可以让律师读得更快、查得更多、写得更快、检查得更细，但它最终能做到什么程度，取决于律师能不能发现问题、判断证据、选择策略、审核结果。

**把执行交给AI，把判断留给律师。**

AI越强，律师真正不可替代的价值越清楚：**判断。**
