# AI实战41｜开庭前，让Agent把整个案件整理成一份庭审提纲

开庭前最实用的内部文件不是“庭审手册”，而是律师行业更常用的庭审提纲。它应当把庭上可能用到的信息尽量集中到一份文件里，减少律师在起诉状、证据目录、质证意见和案件分析之间来回翻找。

## 一、直接把最终版起诉状全文放进去

法官要求陈述诉请和事实理由时，律师可以直接看提纲。必须使用最终提交版本，避免提纲和法院收到的版本不一致。

## 二、证据目录也全文纳入

把证据编号、名称、页码和证明目的全部放进提纲；每组证据下面还可以附可能质疑和我方回应。

## 三、按照真实庭审流程组织

包括法庭调查阶段陈述、预计争议焦点、我方各焦点观点、举证质证、法官可能发问、对方可能发问、建议回答、法庭辩论和最后陈述。

## 四、提前模拟最难的问题

尤其是质量纠纷里的“为什么维修”“有没有验收”“质量异议何时提出”“为什么可以主张全部货款”等不利问题。回答必须有材料依据，没有依据的标【需律师/当事人确认】。

## 五、增加速查信息

关键时间线、合同总价、已付款、未付款、各批货物和违约金计算等最好放在前部，庭上随时查。

## 六、继续沿用自己的庭审提纲模板

让Agent延续章节顺序、表述习惯和Word版式，最终目标是开庭时主要看这一份文件。

## 直接复制的实战提示词

请根据【起诉状最终版】【被告答辩状】【双方证据目录及材料】【案件分析报告】【质证底稿/质证意见】起草【庭审提纲.docx】，并以【历史优质庭审提纲模板】作为结构、格式和表达参考。请将最终版起诉状全文和我方证据目录全文直接纳入提纲，同时整理关键时间线、关键金额、法庭调查阶段陈述、预计争议焦点、我方观点、对方可能答辩和质疑、法官及对方可能发问与建议回答、我方举证、对方证据质证、法庭辩论和最后陈述。所有回答必须有材料依据，无法确认的标记【需律师/当事人确认】。

## 最后记住一句话

庭审提纲不是再写一篇案件总结，而是：**法官现在问这个问题，我马上能在同一份文件里找到答案。**
