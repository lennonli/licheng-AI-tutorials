# AI实战26｜客户抛来一个复杂法律问题，让Agent直接做一份专项法律研究报告

客户经常会抛来一个无法用一句法条回答的问题：能不能做、风险多大、监管怎么看、类似案件怎么处理。这样的任务适合让Agent做真正的专项法律研究，而不是在聊天框里给一个即时结论。

## 一、先把事实和问题拆开

先读取客户背景和材料，列出已确认事实、待确认事实以及真正需要回答的法律问题。

## 二、至少做四层检索

现行法规通过法规库或官方来源核验；司法实践通过案例数据库检索；证券或监管问题再查相关审核/监管案例；最后回到内部知识库和历史项目经验。

## 三、不同来源相互验证

法规讲规则、案例讲裁判、监管案例讲实践、内部库讲经验。若结论冲突，应解释差异，而不是选最有利的一条。

## 四、研究报告要给行动答案

除了法律依据，还应回答可行性、主要风险、需要补什么材料、有哪些替代路径和下一步动作。最终格式直接调用通用指令中既定的法律文件格式。

## 直接复制的实战提示词

请处理【专项法律问题】。先阅读【客户事实材料/项目底稿】，区分已确认事实与待确认事实并拆解核心法律问题；随后分别通过【法规数据库/官方来源】【案例数据库MCP】【证券或监管数据库（如相关）】【内部知识库】进行检索和交叉验证。最终形成【专项法律研究报告.docx】，包括事实、问题、法律依据、案例/监管实践、分析、结论、风险、替代方案和待补材料。最终报告请调用并严格遵守通用指令中已经确定的法律文件格式。

## 最后记住一句话

复杂法律问题不要追求“马上有答案”。**先把事实、规则、案例和实践接起来，答案才有专业价值。**
