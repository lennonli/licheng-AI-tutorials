# AI实战49｜没变化别来打扰我：让Agent持续监控诉讼、处罚、监管和项目变化

有些事情不值得每天人工查，但一旦变化就很重要：客户新增诉讼处罚、公司股权和董监高变化、IPO出现新审核案例、法规从征求意见变成正式发布、许可证即将到期。最适合的模式是条件监控：没变化不打扰，有变化再通知。

## 一、先建立基准状态

第一次记录当前诉讼、处罚、工商、审核案例或法规状态。后续每次只比较新旧差异。

## 二、通知不仅要说“变了”

应列上一状态、本次状态、具体变化、来源、风险等级，以及可能影响哪份尽调报告、法律意见书或项目。

## 三、先定义什么变化值得通知

股权、董监高、注册资本、重大诉讼处罚、核心资质等可以高优先；普通电话、邮箱字段变化则不必打扰。

## 四、不同用途拆成不同监控

客户风险监控、IPO审核案例监控、法规状态监控、合同/许可证期限监控分别设置，更容易维护。

## 五、公开变化只是线索

监控发现新处罚或诉讼后仍要核实是否同一主体、是否生效、金额性质和具体影响，不能直接写进正式法律结论。

## 直接复制的实战提示词

请持续监控【公司/项目/法规/案件/监管问题】并与上一次核查结果比较。重点关注【诉讼仲裁、执行、行政处罚、监管措施、股权及董监高变更、重大资质、交易所新增审核案例、法规正式发布/生效、合同及许可证期限等指定事项】。如本次没有实质变化，请不要通知；只有出现新增、变更、到期、失效或达到预设重要程度的变化时再提醒。通知需列明“上一状态、本次状态、具体变化、原始来源、风险等级、可能影响的项目/法律文件及建议进一步核查事项”，未经核实的公开信息不得直接作为正式法律结论。

## 最后记住一句话

有些事情不值得律师每天亲自查，但值得：**一直有人替你盯。没变化不打扰，一有变化就告诉你。**
