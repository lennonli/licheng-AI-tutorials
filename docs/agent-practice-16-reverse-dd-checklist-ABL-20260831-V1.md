# AI实战16｜尽调报告写出一稿后，让Agent反向生成补充尽调清单

尽调报告写出第一稿后，往往会发现第一轮清单没有问到的问题。这个时候最有效的动作不是继续硬写，而是让Agent从报告里的缺口反向生成第二轮补充尽调清单。

## 一、先抓报告里的未决标记

扫描【待核验】【待补充材料】【待客户确认】、Word批注、前后冲突和证据不足的结论，形成问题池。

## 二、先回头查现有资料，避免重复要

报告说“缺材料”，不代表客户真的没给。Agent应先在现有尽调目录和客户回复中搜索，确认确实没有或版本不够，再向客户提出。

## 三、把要求写得能直接回复

区分“补文件”“确认事实”“解释原因”“提供最新版本”。例如不要写“请补充劳动用工资料”，而应明确期间、人员、文件类型和需要说明的事项。

## 四、继续沿用原尽调清单编号

新的补充问题仍归到原清单序号下，便于客户回复、文件归档和报告更新形成闭环。

## 直接复制的实战提示词

请根据【尽调报告V1】、【现有尽调目录】和【原尽调清单】生成第二轮【补充尽调清单.xlsx】。先提取报告中的【待核验】【待补充材料】【待客户确认】、批注和事实冲突，并回查现有资料，已经提供的不得重复索取。请严格沿用原清单编号，区分“补充文件/事实确认/原因说明/最新版本”，每项要求写到客户可以直接回复，并设置“公司回复、对应文件”栏。

## 最后记住一句话

第一轮尽调清单来自经验，第二轮清单应该来自：**已经写出来的报告缺什么。**
