# AI实战40｜对方证据来了，先让Agent逐份做质证底稿，再形成正式质证意见

对方证据来了，不要直接让AI写一份“真实性、合法性、关联性均不认可”的模板式质证意见。更实用的做法是先逐份做质证底稿，研究清楚每份证据的证明目的、证据链缺口和我方反证，再形成正式意见。

## 一、先盘点证据和证明目的

逐份列证据编号、名称、页码、形成时间、制作主体和对方证明目的。同一份证据可能同时想证明质量问题、及时异议和卖方知情，应拆开分析。

## 二、质证重点是“能证明到什么程度”

照片真实不等于能证明是本案货物，也不等于能证明缺陷由卖方造成；内部不良统计表也不等于客观检测结论。

## 三、质量检测重点看样品对应

检查送检人、时间、样品来源、封样、批次、检测项目和合同质量标准。样品无法对应涉案货物，证明力就需要重新判断。

## 四、聊天、维修和损失都要看完整链条

售后“我们处理”不当然等于承认全部质量责任；下游索赔函不等于损失已实际发生；损失总额要拆成各项并核凭证、因果关系。

## 五、先底稿，律师确认后再套自己的质证模板

历史模板负责格式和表述习惯，当前案件证据决定内容。

## 直接复制的实战提示词

请阅读【被告全部证据及证据目录】【被告答辩状】【我方案件材料及事实—证据对应表】，逐份制作本案质证底稿。对每份证据提取证明目的，并从真实性、完整性、关联性、形成过程和证明力分析，重点核查检测样品与涉案货物对应、质量异议时间、售后维修是否构成责任承认、损失金额和因果关系，同时列明我方反证。先生成【对方证据质证底稿.xlsx】，不要直接形成正式意见；律师确认后，再以【历史优质质证意见模板】起草【正式质证意见.docx】，只学习模板写法。

## 最后记住一句话

质证真正要回答的不是“认不认可”，而是：**对方想证明什么，这份证据实际上又能证明到什么程度。**
