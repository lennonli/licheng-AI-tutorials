# AI实战15｜别让Agent一次写完整份尽调报告：一章一章改，写完一章就核一章

有成熟历史尽调报告时，最不推荐的做法是让Agent一次性重写整份报告。更稳妥的方式是：以历史模板为骨架，用新项目材料一章一章替换和核验。

## 一、模板不是从零起草

历史成熟报告提供结构、编号、表格和表达习惯。但旧项目的公司、股东、金额、日期、风险和结论必须全部清掉，只能用当前项目材料重建事实。

## 二、一次只处理一个章节

例如本次只改“历史沿革”，读取对应尽调文件夹；完成后自检、律师复核，再进入“主要资产”。下一章应基于已经确认的当前报告版本继续，而不是每次回到旧模板。

## 三、不确定内容直接留在报告里

材料不足、冲突或尚未确认时，用【待核验】【待补充材料】【待客户确认】或Word批注明确留下，不要为了让报告看起来完整而补写结论。

## 四、最后再做全篇一致性

所有章节完成后，再统一检查旧项目残留、数字、表格与正文、交叉引用、编号和格式。

## 直接复制的实战提示词

请以【历史成熟尽调报告模板】为基础更新当前项目。本次只处理【指定章节】，其他章节不得修改；只读取【对应尽调资料目录】，所有事实必须来自当前项目材料。保留模板的结构、编号、表格和表达习惯，但彻底删除旧项目主体、股东、金额、日期、风险和结论。无法确认的内容标记【待核验/待补充材料/待客户确认】。完成后自检旧项目残留、数字和表格一致性，并另存新版本供律师确认后再处理下一章。

## 最后记住一句话

尽调报告越长，越不要让AI一次写完。**一章一章改，写完一章就核一章。**
