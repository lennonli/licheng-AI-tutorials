# AI实战14｜尽调目录建好了，再让Agent按清单自动归类客户材料

目录建好以后，下一步就是把客户发来的大量材料归进去。这里最重要的不是“自动移动”，而是保护原始材料、按内容归类，并且归档前后能够对账。

## 一、原始资料先锁住

把客户原始文件放在独立目录，例如`00-客户原始资料/`。Agent只能复制到尽调目录，不得移动、删除或改写原件。归档前先统计文件总数、类型、重复/版本、加密、损坏和无法读取项。

## 二、按实际内容对应清单序号

不能只看文件名。Agent应读取文件内容，严格归入既有尽调清单目录。一个文件涉及多个事项时，可以选择主要归档位置，同时在相关事项索引中建立引用；无法判断的进入“待确认”。

## 三、归档后必须对账

输出材料索引和异常清单，记录原始文件名、归档位置、是否重命名、版本关系。最终核对成功归档、待确认、无法读取等数量与归档前总数是否一致。

## 直接复制的实战提示词

请整理【00-客户原始资料目录】并归档至【已按尽调清单编号建立的目录】。原始文件不得移动、删除或修改，只能复制。先统计文件总数、重复/版本、加密/损坏及无法读取项；归档时必须读取实际内容并严格按现有清单序号分类，清单不存在的层级不得自行新增。多事项文件采用“主要位置+相关索引”，无法判断的标记【待确认】。完成后生成【材料索引.xlsx】和【异常清单.xlsx】，并核对归档数量与原始总数。

## 最后记住一句话

归档前知道有什么，归档中知道每份材料去哪，归档后做到：**一份不丢。**
