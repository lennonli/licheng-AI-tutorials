# AI实战43｜判决下来以后，让Agent拆解法院理由，再判断要不要上诉

一审判决下来以后，不要只让AI做判决摘要。把起诉状、答辩状、证据、庭审提纲、代理词和判决一起交给Agent，反向拆解法院到底采纳了什么、没有采纳什么，以及有没有值得上诉的错误。

## 一、先拆法院的事实、焦点和结论

区分法院认定的事实、归纳的争议焦点、证据采信、法律适用和最终裁判理由。

## 二、与双方核心观点逐项对照

我方哪些观点被采纳、部分采纳或未采纳；对方哪些抗辩被支持。不要只看谁赢，而要看法院采用了谁的哪条逻辑。

## 三、特别找判决没回应和论证跳跃

例如关键质量异议期限没有回应，或者从“卖方维修”直接推到“全部货物不合格”。这些可能成为上诉分析重点。

## 四、法律适用重新核

通过法规和案例数据库核查条文、举证责任、质量异议、减价、抵销等规则，必要时针对一审具体理由补一轮类案检索。

## 五、上诉点按强中弱评估

不是输了就自动找十个理由，而是判断某个错误是否有材料支持、二审能否纠正、纠正后是否可能改变结果。

## 六、也可以做案件复盘

即使不上诉，也总结案件真正胜负点、最关键证据和以后同类案件应提前准备什么。

## 直接复制的实战提示词

请根据【一审判决书】【起诉状】【被告答辩状】【双方证据及质证意见】【庭审提纲】【代理词】进行判决分析。拆解法院认定事实、争议焦点、证据采信、法律适用和裁判理由，并逐项对照我方观点与对方抗辩，标记【采纳/部分采纳/未采纳/判决未回应】。重点检查质量问题、质量异议、维修、拒付货款、损失和抵销是否存在事实依据不足、论证跳跃、法律适用或举证责任问题；对可能上诉点通过【法规/案例数据库MCP】补充核验，并按【强/中/弱】评估是否可能影响结果。先生成【判决分析及上诉评估报告.docx】，不要直接起草上诉状。

## 最后记住一句话

判决分析真正要问的不是“赢了多少”，而是：**法院为什么这么判，这条逻辑有没有可能在二审被重新审查。**
