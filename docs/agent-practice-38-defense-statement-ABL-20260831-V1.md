# AI实战38｜如果你代理被告，怎样让Agent起草一份真正能用的答辩状

如果这次我们代理的是买方，也就是被告，答辩状同样不要让AI一句“尽量反驳原告”就开始写。真正能用的答辩状，应先逐项回应起诉状，再围绕质量问题建立完整的事实和证据链。

## 一、先拆原告每个主张

把诉讼请求和事实逐项列出，区分【认可】【不认可】【部分认可】【需补充说明】。真正的答辩不是把所有事实都否认。

## 二、质量抗辩必须具体

先确定合同、技术协议、图纸、样品、国家/行业标准中的质量要求，再写清具体缺陷、批次、数量、发现时间和处理过程。

## 三、解释为什么质量问题影响付款

核心逻辑可能是付款条件未成就、应减价、存在损失可抵销等。不能只说“货有问题”，却没有解释为什么可以拒付剩余货款。

## 四、损失和反诉单独判断

损失要拆成返工、停产、下游索赔等并逐项找证据；是否反诉由律师决定，Agent只能提示，不得擅自在答辩状增加请求。

## 五、仍然用历史优质答辩状模板

模板学习结构和文风，当前案件材料决定事实。先形成答辩框架，经律师确认后再写全文。

## 直接复制的实战提示词

请代理【买方/被告】处理本案。先阅读【原告起诉状及证据】【我方案件材料】【质量异议、检测、维修、损失等证据】，逐项拆解原告诉请和事实，区分【认可/不认可/部分认可/需补充说明】，并先形成“原告诉请—我方答辩—对应证据”表和答辩框架。重点分析质量标准、具体质量问题、异议时间、卖方售后、付款条件、减价/赔偿/抵销及是否可能反诉。框架经律师确认后，以【历史优质答辩状模板】为结构和表达参考起草【民事答辩状_初稿.docx】，不得继承旧案事实，缺乏证据的内容标记【待核验/待补证】。

## 最后记住一句话

答辩不是“把原告全部否认掉”，而是：**承认无争议事实，把火力集中到真正决定责任的争议点。**
