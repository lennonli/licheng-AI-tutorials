# 庭审提纲、庭审提醒与诉讼归档教程

> 诉讼实战系列（九）｜适用：AI智能体（提纲生成 + 定时任务提醒 + 归档结构化）｜2026-08-27
> 用途：开庭前的最后一公里与结案后的最后一公里——提纲、提醒、归档闭环。

## 一、它能解决什么问题

庭前怕**遗漏和迟到**（漏带原件、错过举证期限），庭后怕**案卷失散**（判决书、笔录散落各处）。本教程用 AI 生成提纲与备忘、用定时任务盯死所有期限、用统一结构归档，并把归档成果接到执行阶段（系列三）。

## 二、输入材料

- 案卷材料与证据体系：系列六《证据目录》、系列八质证意见表
- 庭审信息：【法院、开庭时间、案号、承办法官（如已知）、庭审预计时长】
- 模拟对抗结论（如已做）：系列一《庭前对抗演练复盘报告》
- 本所既往案件归档结构或结案卷宗模板：【路径】

## 三、AI智能体能力配置

| 环节 | 用什么 |
| --- | --- |
| 庭审提纲生成 | 主对话（汇总系列一/六/八成果） |
| 期限与开庭提醒 | AI智能体定时任务：开庭前 7 天/前 1 天/当天早 8 点三级提醒；举证期限届满提醒；上诉期提醒（接系列七） |
| 判决书识别归档 | 本地 OCR（扫描判决书）→ 结构化登记 |
| 代理人报告 | Word 文档生成能力 + 模板复用 |
| 执行衔接 | 转系列三（强制执行与财产线索） |

## 四、标准工作流与提示词模板

### 第一步：庭审提纲（核心交付物一）

```text
汇总【证据目录】【质证意见表】【模拟对抗复盘（如有）】，生成《庭审提纲》（Word）：
1. 法庭调查阶段：
   - 我方陈述要点（3分钟版提词）；
   - 对我方当事人的法庭可能发问 + 建议回答口径（接模拟法官角色结论）；
   - 对对方当事人/证人的发问清单（每个问题标注目的与预期回答）；
2. 举证质证阶段：
   - 我方举证顺序与每组一句话说明；
   - 对对方证据的质证意见速查表（浓缩自质证意见表，按对方证据编号排列）；
   - 对方可能突袭证据的应对预案；
3. 法庭辩论阶段：争议焦点逐项的 1 分钟核心观点卡；
4. 最后陈述：30 秒要点。
格式紧凑可打印，单页信息密度优先。
```

### 第二步：庭前提醒设置（定时任务）

```text
为本案建立定时提醒（用 AI智能体定时任务能力）：
1. 开庭提醒：开庭前 7 天（准备期检查）、前 1 天（材料齐备）、当天早 8 点（出发提醒）；
2. 期限提醒：举证期限届满前 3 天；上诉期届满前 7 天/3 天（如败诉预案）；
3. 事务提醒：原件核对（前 1 天）、证人到庭确认（前 2 天）。
每条提醒通过对话和邮件【邮箱】送达，正文含案号、事项、需携带材料清单；
提醒指令写入任务描述：最终动作、收件人、无变化也简报（防静默失败）。
```

### 第三步：庭后即时归集

```text
庭审结束当天：
1. 整理庭审新增材料清单（对方当庭提交、法庭调取）；
2. 更新待办：代理词提交期限、补充证据期限（各设定时提醒）；
3. 生成一页《庭审当日纪要》：法庭新查明事实、法官新关注点、我方未答事项——
   作为代理词（系列八第三步）的补充输入。
```

### 第四步：结案归档（核心交付物二）

```text
收到【判决书/调解书】后执行归档流程：
1. 文书处理：OCR 提取全文 → 结构化登记（案号、裁判日期、结果、主文金额、利息计算口径）；
2. 案卷目录生成：按【本所归档结构模板】生成卷宗目录
   （起诉应诉材料—证据—庭审笔录—代理词—裁判文书—执行材料各编），
   电子卷标注每份文件路径；
3. 《结案报告》要素表：案件结果与预期对比、关键得失点（接系列四复盘结论）、
   可复用经验（沉淀进知识库）；
4. 执行衔接判断：文书生效日、履行期届满日推算——如需执行，转系列三流程
   并为履行期届满日设定时提醒；
5. 判决引用法条经北大法宝核验后，方可在结案报告中作为"裁判依据"引用。
```

## 五、模板复用原则

庭审提纲、结案报告、卷宗目录：**优先使用律师提供的其他项目更优模板/归档结构**，AI 做内容填充与结构沿用；新起草部分单独标注。

## 六、红线

1. 所有提醒日期以**传票、期限裁定等正式文书为准**，推算日期标注"推算"；
2. 归档保留原始扫描件，OCR 件仅为检索辅助；
3. 结案报告中的经验沉淀注意脱敏（案件对外表述口径）；
4. 提醒任务定期检查静默失败（每条任务要求"无变化也简报"）。
