# AI实战31｜报告期要更新了，先让Agent生成一份补充尽调清单

证券项目报告期更新前，不应先让企业“把最近的新资料都发来”。更高效的第一步，是让Agent基于上一期尽调成果，先生成一份新的“更新报告期补充尽调清单”，让企业知道哪些材料真的需要更新。

## 一、不是把旧清单原样再发一遍

上一期已经完整核过的历史设立、早期增资、旧股权转让等事项，如果本期没有变化，就没必要重复索取。重点应放在会随日期变化的动态事项。

## 二、先读上一期成果再出清单

让Agent读取上一期尽调清单、法律意见书、律师工作报告、尽调报告、客户回复和相关底稿，理解截至原截止日已经核到什么程度。

## 三、重点识别动态资料

工商和治理、股权、资质、主要资产、知识产权、重大合同、诉讼处罚、劳动用工、关联方、担保借款等都可能随报告期变化。

## 四、把上一期未决和到期事项带进来

扫描【待核验】【待补充】【持续关注】以及在新旧截止日期之间到期的许可证、合同、承诺、整改期限等，自动进入本轮补充清单。

## 五、要求要写具体

区分【必须更新】和【如有变化请提供】，并继续沿用原尽调清单编号，设置企业回复和对应文件栏。

## 直接复制的实战提示词

请为本项目生成【更新报告期补充尽调清单.xlsx】。上一核查截止日为【原日期】，本次更新至【新日期】。请先阅读【上一期尽调清单、法律意见书/律师工作报告/尽调报告及相关底稿】，识别会随报告期变化的事项、上一期仍存在的【待核验/待补充/持续关注】以及新增期间内到期的资质、合同、承诺等。严格沿用原尽调清单序号，逐项明确企业本次需提供或确认的新增、变更、续期、终止和最新状态资料，区分【必须更新】与【如有变化请提供】，并设置“企业回复、对应文件”栏。不得机械重复本期无变化的历史资料。

## 最后记住一句话

报告期更新的第一步，不是更新法律意见书，而是先回答：**从旧截止日到新截止日，哪些资料按性质就应该重新更新一次？**
