# AI实战29｜问询回复写完后，换一个Agent逐题检查漏答、答非所问和明确意见

问询回复写完以后，起草Agent往往很难发现自己的漏答。重要题目最好换一个完全独立的Agent，把原问询和回复重新逐项对照。

## 一、复核Agent先独立拆题

不要直接给它现成任务表。让它自己重新拆一遍问询，形成新的子问题清单，再与回复逐项映射。

## 二、重点找四类问题

漏答、只答了一半、答非所问、应该发表明确意见但没有形成明确结论。

## 三、再核数据和材料支撑

检查回复中的数字、期间、主体、整改和结论是否与招股书、法律意见书等申报文件一致，是否用历史案例替代了当前事实。

## 四、可以模拟监管追问

让独立Agent站在审核人员角度列出最可能继续追问的问题，帮助项目组提前补强。

## 直接复制的实战提示词

请作为未参与主要起草的独立复核Agent，阅读【原始问询函】【当前问询回复】以及【招股书/法律意见书等关键申报文件】。请先独立重新拆解每一个问询子问题，再建立“子问题—回复位置—是否完整回答”映射，重点检查【漏答】【部分回答】【答非所问】【缺少明确中介意见】、数据不一致、事实支撑不足和结论过强/过弱。先生成【问询回复独立复核表.xlsx】，不要直接修改；另列出最可能的监管追问。

## 最后记住一句话

问询回复写完后的最佳检查不是“再读一遍”，而是：**让另一个Agent重新做一次这道题。**
