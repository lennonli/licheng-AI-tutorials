# AI实战32｜企业补完更新资料后，让Agent先做增量核查，再更新法律文件

企业按照更新清单补完资料以后，也不要马上让Agent修改法律意见书。先做增量核查：比较新旧报告期、重新跑一轮MCP和公开核查、形成变动表和更新计划，律师确认后再改文件。

## 一、先核对企业是否把清单答完

把上一轮更新清单与实际新增资料逐项对应，标记已提供、部分提供、未提供、回复不完整。材料没收齐，就不要假装可以完成全部更新。

## 二、识别新增、变更、到期和新进展

把上一期成果与本期新增材料放在一起，区分无变化、新增、变更、终止/到期、原事项新进展和仍待核验事项。

## 三、企业材料之外再做外部更新核查

重新调用工商、诉讼、知识产权、证券监管等MCP或连接器；接口不可用时改用相应官方渠道。企业提供是一条线，外部核查是另一条线。

## 四、先生成报告期变动表和更新计划

列明上期状态、本期变化、核查来源、需要进一步核查的内容、拟影响的法律文件章节。律师先确认计划。

## 五、确认后只更新受影响章节

从上一版已确认法律文件继续修改，不重写无变化内容；原【待核验】只有在新材料足以解决时才能删除。最后再做新旧版本对比和本轮更新说明。

## 直接复制的实战提示词

请根据【上一报告期法律文件及底稿】【本次更新报告期补充尽调清单】【企业本轮新增资料】开展增量核查。原截止日为【原日期】，新截止日为【新日期】。先核对清单完成情况，再识别新增、变更、到期、终止、原事项新进展和仍待核验事项；同时调用【工商/诉讼/知识产权/证券监管等MCP】，不可用时改用官方渠道。先生成【报告期变动表.xlsx】和【补充法律尽调更新计划.md】，本阶段不要修改法律文件。待律师确认后，仅更新受影响章节并另存新版本，最后生成本轮更新说明。

## 最后记住一句话

报告期更新不是重新做一遍项目，而是：**查变化、列变化、做计划、律师确认，再增量更新。**
