# AI实战12｜尽调材料太多？先让Agent做资料盘点和缺失清单

尽调项目刚开始时，最容易直接陷入“看文件”。但真正高效的第一步，是先知道客户到底提供了什么、缺了什么、哪些材料可能有问题。

## 一、先对照尽调清单盘点

以既有尽调清单为基准，将客户材料对应到每个序号，区分已提供、部分提供、未提供、无法读取、版本异常。

## 二、不要只看文件名判断已提供

“营业执照.pdf”可能是旧版，“合同.zip”里可能只有部分合同。Agent应读取实际内容后再判断是否满足清单要求。

## 三、输出可以直接发给客户的缺失清单

不要写“资料不全”。应明确缺什么、为什么缺、需要客户补什么版本或说明，并预留客户回复和对应文件栏。

## 直接复制的实战提示词

请根据【尽调清单路径】和【客户材料目录】进行资料盘点。严格按尽调清单序号逐项核对，读取实际文件内容后标记【已提供】【部分提供】【未提供】【版本待确认】【无法读取】；不得仅凭文件名判断。最终生成【尽调资料盘点表.xlsx】和【缺失/补充资料清单.xlsx】，具体写明需要补充的材料、原因、客户回复栏及对应文件栏。

## 最后记住一句话

尽调的第一步不是“开始写报告”，而是：**先知道材料够不够。**
