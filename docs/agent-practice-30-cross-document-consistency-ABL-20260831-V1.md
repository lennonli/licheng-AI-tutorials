# AI实战30｜多家中介文件别各写各的：让Agent做一次跨文件一致性核对

IPO、再融资、新三板项目里，同一家公司会同时出现在招股说明书、法律意见书、审计报告、问询回复等多份文件中。真正危险的是不同中介描述成了“不同的公司”。

## 一、统一抽取同一事项

围绕主体信息、历史沿革、股权、客户供应商、重大合同、财务数据、资产、关联方、诉讼处罚等，从各文件提取对应记载。

## 二、先统一口径再判断冲突

日期可能是股东决议日、出资日、工商变更日；金额可能因单位、四舍五入、合并范围和期间不同而不同。先统一截止日、单位和统计范围，不能看到数字不同就报错。

## 三、检查“遗漏型不一致”

不仅找A写100、B写120，还要找某重大处罚只在法律意见书里出现、招股书却没有相应风险披露等情况。

## 四、发现冲突后回到底稿

不要用“多数文件都这么写”来选答案。应回到原始合同、工商、财务或其他底稿，由项目组确认正确口径。

## 直接复制的实战提示词

请对【招股说明书】【法律意见书/律师工作报告】【审计报告及财务报表】【问询回复及其他申报文件】进行跨文件一致性核对，本次不要修改文件。按主体信息、历史沿革、股权、财务、客户供应商、重大合同、资产、关联方、诉讼处罚等逐项提取记载，并在统一单位、统计口径和截止日期后判断实质不一致、遗漏披露或结论冲突。最终生成【多中介文件交叉核对表.xlsx】，无法判断正确版本时标记【待项目组确认】，不得以多数文件内容代替原始底稿。

## 最后记住一句话

多中介文件核对的核心只有一句：**大家必须讲的是同一家公司、同一组事实。**
