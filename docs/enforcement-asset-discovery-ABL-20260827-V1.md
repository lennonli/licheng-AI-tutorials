# 强制执行与财产线索教程

> 诉讼实战系列（三）｜适用：AI智能体（企查查/天眼查 + 网核留痕 + 定时任务监控）｜2026-08-27
> 用途：胜诉后把钱要回来——财产线索调查、执行文书起草、执行全程跟踪。

## 一、它能解决什么问题

执行阶段律师的三大痛点：**找不到财产、文书反复补、节点没人盯**。本教程用主体调查工具摸线索、用模板复用出文书、用定时任务盯节点，把执行案件做成可持续跟踪的流程。

## 二、输入材料

- 生效法律文书：【判决书/调解书/仲裁裁决书路径】
- 被执行人：【名称/姓名、身份证号或统一社会信用代码】
- 本所其他项目的执行文书模板（如有）：【路径】（优先使用）
- 执行法院：【法院名称】

## 三、AI智能体能力配置

| 环节 | 用什么 |
| --- | --- |
| 被执行人画像 | 企业信息库（企查查 MCP 或天眼查）:工商/股权/对外投资/分支机构 |
| 涉执与失信核查 | 企业信息库的被执行人/终本案件查询；中国执行信息公开网（人工或网核 skill 留痕） |
| 财产线索网核 | 网络核查留痕技能（如 network-check-v3）：不动产登记公开信息、招投标中标（中标价=现金流线索）、股权变更记录，全部 PDF 留痕 |
| 执行文书起草 | Word 文档生成能力 + 模板复用原则（见第五节） |
| 执行节点跟踪 | AI智能体定时任务：终本案件、恢复执行、股权冻结到期、限制高消费变动，定期查并邮件推送（衔接培训课程表第 17 课舆情监控方法论） |
| OCR | 本地 OCR（如 ocrmac）识别判决书扫描件 |

## 四、标准工作流与提示词模板

### 第一步：被执行人全景画像

```text
对被执行人【名称】输出执行视角画像：
1. 基本工商信息与经营状态（是否吊销/注销/迁址）；
2. 既有被执行记录：案号、标的、是否终本、终本日期——判断本次执行的可回收性；
3. 对外投资与分支机构清单（追加被执行人/代位执行的线索入口）；
4. 股权冻结与出质记录（在冻的顺位与到期日）；
5. 招投标中标记录（近2年）——经营现金流的间接信号；
6. 关联企业（一层）：法定代表人/股东重合情况，注意财产混同线索。
全部信息注明数据来源与查询日期；仅供执行线索参考。
```

### 第二步：财产线索清单与网核留痕

```text
基于画像输出《财产线索清单》，每条线索注明：
线索类型（银行账户/不动产/股权/到期债权/车辆/知识产权/应收账款）、
线索依据（数据来源）、建议查控方式（法院网络查控/律师调查令/追加被执行人）、
优先级。
然后对可网络核查的线索逐项执行网核留痕流程：
保存可追溯的 PDF 证据文件，按"线索—来源—证据文件路径"登记。
无法核实的一律标注"待法院查控"，不得推测。
```

### 第三步：执行文书起草（模板复用）

```text
起草【执行申请书/恢复执行申请书/追加被执行人申请书/查封申请】：
【优先】以我提供的其他项目模板【路径】为基准，只做本案事实填充：
当事人信息、执行依据（案号、文书生效日、给付内容）、
执行请求（金额=本金+迟延履行期间债务利息，附计算表：
按日万分之一点七五分段计算至【预计申请日】，列出计算过程）、
财产线索（引用第二步清单）。
保留模板结构、编号、签署页格式；我没有模板的部分再按律所格式起草。
输出 Word + 修改说明（哪部分基于模板、哪部分新起草）。
```

### 第四步：执行全程跟踪（定时任务）

```text
为本案建立执行跟踪定时任务：
1. 每周核查被执行人涉执、股权冻结、限高、失信变动（企查查/天眼查）；
2. 触发条件式提醒：终本案件恢复财产线索、冻结到期前30天（提示续封）、
   被执行人新增中标/新设公司（财产线索）；
3. 有变动时邮件推送【邮箱】，正文含变动摘要与证据文件；
4. 无变动时每周发一行"无变化"简报，防止静默失败。
（按 AI智能体定时任务搭建：一个任务管一件事，指令写清最终动作与收件人。）
```

## 五、模板复用原则

执行文书**优先用律师认为更好的其他项目模板**：AI 只填事实、调口径、算利息，不动模板骨架；无模板的才新起草，并在修改说明中区分标注。

## 六、红线

1. 迟延履行利息计算（日万分之一点七五）须人工复核起算日与分段；
2. 财产线索只提交法院查控，禁止任何形式的自行调查越界（如非法获取账户流水）；
3. 追加被执行人须严格对照法定情形，检索类案支撑并核验案号；
4. 定时任务推送内容注意脱敏（邮件主题不含案卷敏感信息）。
