# AI实战23｜IPO遇到特殊法律问题？让Agent去证券数据库里找审核案例

IPO项目遇到无证房产、劳务派遣、历史代持等特殊问题时，最有价值的不是让AI给一个抽象法律答案，而是去看交易所过去到底怎么问、发行人和律师到底怎么答。

## 一、先描述当前项目事实

把当前问题的规模、持续时间、整改状态、占比、是否核心经营场所等关键事实交给Agent。只有先理解项目，案例才有可比性。

## 二、用证券数据库做同义词扩展

例如“无证房产”还可能出现“违章建筑”“未办理产权证”“规划手续不完善”等表述。Agent应结合内部IPO知识库、见微等证券数据库或其他连接器扩展检索。

## 三、提取监管真正关心的内容

不仅记录“问了这个问题”，还要提取交易所追问、发行人回复、律师核查、整改措施和最终披露。

## 四、成功上市不等于该问题被无条件认可

案例只能说明当时事实和回复路径。不同板块、时间、问题严重程度、整改程度都可能导致不同监管判断。

## 直接复制的实战提示词

请根据【当前IPO项目事实】通过【内部IPO知识库/证券数据库MCP或连接器】检索与【特殊法律问题】相关的历史审核案例。请扩展同义词，优先选择同板块、较新且事实接近的项目，逐案提取监管问询、发行人回复、律师核查程序、整改措施和最终披露，并从规模、占比、持续时间、是否核心经营、处罚/证明、替代方案等维度与当前项目比较。最终生成【证券审核案例研究报告.docx】并保留原始来源。

## 最后记住一句话

IPO特殊问题最值得查的不是“法律教科书怎么说”，而是：**监管过去在什么事实下追问、律师怎样把事实讲清楚。**
