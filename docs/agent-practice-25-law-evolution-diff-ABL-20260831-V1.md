# AI实战25｜案件发生在旧法时期怎么办？让Agent自动做新旧法和法条沿革对比

案件发生在旧法时期，直接拿今天的法条去分析，很容易得出错误结论。新旧法问题最适合让Agent先做“关键日期—法规版本—过渡规则”的时间轴。

## 一、先建立事实时间轴

合同签订、行为发生、权利义务形成、争议发生、起诉或处罚等关键日期先确定。日期不清时先标记，不要急着套规则。

## 二、把法规沿革串起来

找到行为发生时有效版本、后续修改决定、司法解释和现行版本，标明每个版本的施行、失效和衔接时间。

## 三、比较的是法律效果，不只是条号

有些修法只是条号移动，有些则改变责任条件、举证责任或法律后果。Agent应逐项比较实质变化。

## 四、特别检查过渡条款

民事、行政处罚等领域都可能有专门的新旧法衔接规则。不能默认“新法更合理就用新法”。

## 直接复制的实战提示词

请围绕【案件/事项】先建立关键事实日期表，再通过【法规数据库MCP/官方法规来源】梳理相关法律文件的历次版本、施行与失效时间、修改内容和过渡规定。请比较行为发生时版本、争议处理时版本与现行版本的实质差异，并分析各关键事实应适用哪一版本及理由。最终生成【新旧法沿革与适用分析表.xlsx】及【法律适用分析.md】，日期或衔接规则无法确认的标记【待核验】。

## 最后记住一句话

新旧法问题的第一步永远不是找今天的法条，而是：**先问这件事发生时，法律是什么样。**
