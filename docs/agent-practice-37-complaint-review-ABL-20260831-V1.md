# AI实战37｜起诉状写完别急着提交：让另一个Agent从被告和法官两个角度复核

起诉状初稿完成后，不要只查错别字。最好换一个没有参与主要起草的Agent，分别从“被告律师怎么攻击”和“法官第一次看是否看得明白”两个角度做提交前复核。

## 一、被告视角重点找可被反证打掉的表述

例如“全面履行”“验收合格”“从未提出质量异议”等是否比证据走得更远，诉请金额、违约金、付款条件是否有明显攻击点。

## 二、法官视角重点看事实链是否完整

签约、交付、验收、质量异议、售后、付款、催款之间有没有断点；每个诉讼请求是否明确、可计算。

## 三、把关键事实和证据再对应一次

法官如果问“这句话证据在哪”，复核Agent应能找到具体送货单、流水、聊天或其他材料。

## 四、先出问题清单，不要直接改

第二个Agent的策略意见不一定就是最终方案，应先列风险、位置和建议，由律师决定是否修改。

## 直接复制的实战提示词

请作为未参与起诉状主要起草的独立复核Agent，对【起诉状初稿】【事实—证据对应表】【核心案件材料】进行提交前复核。本案为卖方追索货款、买方以质量问题拒付的买卖合同纠纷。先站在【被告律师】角度攻击诉讼请求、付款条件、验收、质量异议、售后和证据薄弱点；再站在【承办法官】角度检查诉请是否明确、事实链是否完整、关键事实是否有证据支持。请先生成【起诉状提交前复核清单.xlsx/报告.docx】，列明问题位置、风险和建议，不要直接修改原稿。

## 最后记住一句话

起诉状写完以后，真正值得问的是：**如果我是被告会怎么打，如果我是法官还有什么看不明白。**
