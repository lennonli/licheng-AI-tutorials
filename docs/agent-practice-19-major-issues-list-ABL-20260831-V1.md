# AI实战19｜100页尽调报告怎么看？让Agent提炼重大问题清单

一份100页尽调报告对律师很重要，但对项目负责人、交易团队或客户来说，真正需要快速掌握的是：哪些问题会影响交易决定。Agent可以把长报告压缩成一份重大问题清单。

## 一、不要做普通摘要

不是每章总结两句话，而是筛选可能影响交易价格、交割条件、交易文件保护、持续经营或需要客户决策的问题。

## 二、按处理方式分类

可以分为：交割前解决、交易文件保护、继续核查、持续关注。每个问题写清关键事实、影响、建议动作和报告位置。

## 三、风险等级要说明理由

“高风险”不能只贴标签，应说明为什么重要、什么事实尚未解决、可能影响什么。最终重大与否仍由律师和项目组判断。

## 直接复制的实战提示词

请阅读【尽调报告最终稿】并提炼【重大问题清单.xlsx/报告.docx】。不要按章节做普通摘要，只筛选可能影响交易决策、价格、交割条件、交易文件保护或需客户决策的事项，并分类为【交割前解决】【交易文件保护】【进一步核查】【持续关注】。逐项列明关键事实、风险/影响、建议动作、对应报告位置及风险等级理由；不得把普通瑕疵机械列为重大问题。

## 最后记住一句话

长报告是底稿，重大问题清单解决的是：**决策的人到底应该先看什么。**
