# AI实战04｜别让AI只在聊天框里写：直接让Agent生成和修改Word文件

很多AI写得很好，但最后还要把聊天框里的文字复制进Word、重新排版。对于Agent，这一步完全可以省掉：让它直接读取真实DOCX，在原格式基础上生成或修改文件。

## 一、直接操作真实文件

合同修改、法律意见、报告更新，都可以要求Agent读取指定DOCX，识别原有标题、编号、表格、页眉页脚和段落结构，再在文件本身上处理。

## 二、模板和原文件不要覆盖

如果是基于历史模板生成新项目文件，应保留模板原件；如果是修改当前项目文件，也应另存新版本。文件名最好体现项目、文书和版本。

## 三、修改后要交付“文件+说明”

除最终DOCX外，再让Agent列出主要修改点、未确认内容和格式异常。重要合同或法律文件还应检查旧项目残留、数字一致性和批注是否清理。

## 直接复制的实战提示词

请直接处理【DOCX文件路径】并生成真实Word文件，不要只在聊天中输出正文。请尽量保留原文件的标题层级、编号、表格、段落和既有格式，根据【具体任务】修改内容；不得覆盖原件，另存至【输出路径】。完成后同时生成简短修改说明，列出关键修改、待确认事项、格式异常及是否发现旧项目残留。

## 最后记住一句话

真正省时间的不是让AI“写一段文字”，而是：**让它直接把可交付的Word文件做出来。**
