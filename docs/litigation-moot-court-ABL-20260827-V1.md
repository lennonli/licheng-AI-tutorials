# AI 模拟法庭与庭审陪练教程

> 诉讼实战系列（一）｜适用：AI智能体（多子代理对抗演练）｜2026-08-27
> 用途：把整段提示词交给 AI（【】内替换为实际信息），在开庭前完成对抗演练与策略校验。

## 一、它能解决什么问题

庭前最大的风险不是"没准备好"，而是"只按自己的思路准备好"。本教程用 AI 多智能体分别扮演**对方律师、承办法官、对方当事人**，对你的代理思路进行对抗性发难，达到三个目的：

1. 开庭前暴露争议焦点和证据链弱点；
2. 预演对方可能的抗辩树与质证套路，提前准备应对；
3. 年轻律师低成本获得"实战对抗"训练。

## 二、输入材料

- 案卷材料目录：【路径】（起诉状/答辩状草案、证据目录、合同与往来函件、鉴定意见等）
- 我方诉讼立场与代理思路：【一段话描述】
- 对方已提交的文书（如有）：【路径】
- 庭审程序信息：【法院、案由、程序（一审/二审）】

## 三、AI智能体能力配置

| 环节 | 用什么 |
| --- | --- |
| 案卷通读与摘要 | 主对话直接读取；扫描件用 本地 OCR（保密件不出机） |
| 对方律师/法官角色 | 派生独立子代理（每个角色一个，互不通气，保证对抗性） |
| 演练中引用法条 | 法规核验子代理（或独立会话）→ 北大法宝 MCP 逐字核验 |
| 类案裁判口径 | 类案检索子代理（或独立会话）→ 元典/北大法宝案例库 |
| 演练结论复核 | 换一个新会话当验收员（参考《额度没了换 AI 续任务》的互搏方法） |

## 四、标准工作流与提示词模板

### 第一步：案情脱敏摘要

```text
读取【案卷材料目录】全部材料，输出一份供对抗演练用的案情摘要（3,000字内）：
当事人用【甲公司】【乙某】等代号，金额保留真实数额；
按"事实时间轴—争议焦点初判—双方证据清单—我方请求权基础"四部分组织。
输出后停下来等我确认，先不要开始演练。
```

### 第二步：构建对方律师子代理（核心）

```text
你现在是【对方当事人】的代理律师，立场与我方完全对立。
材料：【上述案情摘要】。
你的任务：站在你的当事人立场，输出——
1. 你方最可能的三套抗辩策略（事实抗辩/法律抗辩/证据抗辩各至少一套）；
2. 对我方每份证据的质证意见草案（真实性、合法性、关联性逐项）；
3. 你将向法庭申请查明的事实和我方举证的薄弱点；
4. 你预测的三个最刁钻的庭审发问（对我方当事人和证人）。
要求： aggressive 但专业，不要客套。
```

### 第三步：构建法官角色

```text
你现在是本案承办法官（【案由】案件，【法院层级】）。
基于【案情摘要】，模拟庭审：
1. 归纳本案争议焦点（按你的审判习惯排序）；
2. 对双方各提三个庭审询问问题；
3. 指出你认为目前双方举证均未覆盖、需法庭依职权查明或释明的问题；
4. 心证倾向提示：以现有材料，你认为哪些事实主张缺乏证据支撑。
```

### 第四步：对抗轮次演练

```text
基于以上对方律师策略和法官关注点，进行两轮对抗推演：
第一轮：我方对对方三套抗辩逐套给出应对方案（补证/法律反驳/让步空间）；
第二轮：假设对方拿到我方第一轮应对后升级攻击，我方再应对。
输出：每轮结束后的"我方薄弱点变化表"。
```

### 第五步：复盘与策略修正（交付物）

```text
汇总全部演练结果，输出《庭前对抗演练复盘报告》（Word，按律所格式）：
1. 确认的争议焦点与预判对比；
2. 我方证据链弱点清单（附补强建议与取证路径）；
3. 对方发问应对备忘（问题—建议回答口径—风险提示）；
4. 庭审提纲修订建议（在我方现有提纲基础上标注改动）；
5. 所有演练中引用的法条，逐条列出并标注是否已经北大法宝核验，未核验的标【待核验】。
```

## 五、文书类工作的模板复用原则

复盘报告、应对备忘等文书，**优先使用律师提供的其他项目已定稿的更优模板**：AI 只做事实填充和必要的口径调整，不重写模板结构（先长后短替换、最小必要修改、零残留质检——同《北交所三会文件批量起草提示词》的映射表方法）。

## 六、红线

1. 模拟结论**仅供策略参考，不得直接写入对外文书**；
2. AI 扮演角色的"法条引用"默认是回忆不是检索，正式引用前必须回北大法宝逐字核验；
3. 涉密案卷演练前先脱敏；保密程度高的材料不出本机（本地 OCR、不经云端解析）；
4. 演练不能替代真实经验判断——最终策略由主办律师拍板。
