# AI实战03｜让Agent做网络研究：不要只让它“搜一下”

让Agent做网络研究，最差的提示词就是“帮我搜一下”。搜索只是动作，真正的研究还包括确定问题、选择来源、打开原文、去重、比较和形成可追溯结论。

## 一、先定义研究维度

例如研究一家公司，不要只写“查一下背景”，而应明确工商、股权、诉讼处罚、资质、知识产权、新闻、监管等维度；研究一个法律问题，则明确法规、案例、监管实践和行业资料。

## 二、优先原始和权威来源

搜索结果页只能用于发现线索。真正进入结论的内容应尽量打开官网、原始公告、裁判文书、监管文件或专业数据库原文，保留来源、日期和必要定位信息。

## 三、处理同名、重复和冲突

网络研究常见问题是同名主体混淆、转载重复、旧信息覆盖新信息。Agent应先确认主体身份，再对重复结果去重；不同来源冲突时不要自行选一个，而是把冲突列出来。

## 四、输出研究底稿而非网页摘抄

最终成果应至少包括：研究问题、检索范围、关键发现、证据来源、异常/冲突、尚不能确认事项。这样后续律师可以回到原始来源复核。

## 直接复制的实战提示词

请围绕【研究对象/问题】开展系统网络研究，按【研究维度】展开。优先使用【官方/原始/专业数据库】来源，搜索结果只用于发现线索，重要结论必须打开原文核验并保留来源、日期和定位。请先核实主体身份、去重转载信息，并对冲突资料单独标记。最终生成【网络研究底稿.md/报告.docx】，列明关键发现、原始来源、未确认事项和建议进一步核查方向。

## 最后记住一句话

Agent做网络研究，不是“搜得多”，而是：**搜到以后能不能核、能不能比、能不能追溯。**
