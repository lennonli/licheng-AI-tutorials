# AI实战11｜几十份证据怎么整理？让Agent先做证据目录和时间线

诉讼材料一多，最先要解决的不是写起诉状，而是把证据和时间线理顺。Agent可以先替律师完成证据盘点、目录初稿和关键事实时间线。

## 一、证据目录先从“材料是什么”开始

逐份读取文件，识别证据名称、形成时间、主体、页码、主要内容和可能证明事项。不要只根据文件名命名，截图、聊天记录、付款凭证尤其要看实际内容。

## 二、时间线和证据目录要互相对应

把签约、交付、付款、催告、争议、通知等关键时间按顺序排出来，同时注明每个节点对应哪份证据。没有证据支撑的客户陈述要单独标记。

## 三、冲突和缺口提前暴露

同一日期、金额或事实在不同文件里不一致时，不要替律师解释；缺少原件、完整聊天、送达凭证等情况也要列成补证事项。

## 直接复制的实战提示词

请阅读【案件证据材料目录】并生成【证据目录初稿.docx】和【案件时间线.xlsx】。逐份识别证据名称、形成时间、主体、主要内容、页码和拟证明事项；时间线中的每个关键事实应注明对应证据。客户陈述但暂无证据支持的事项标记【待补证】，不同证据在日期、金额、主体或事实上的冲突单独列出，不得自行消解。

## 最后记住一句话

证据整理的目标不是把文件排好序，而是：**让每个关键事实都知道靠什么证明。**
