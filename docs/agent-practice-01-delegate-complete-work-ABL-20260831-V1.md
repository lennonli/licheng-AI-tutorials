# AI实战01｜别再一句一句问AI：把一项完整工作直接交给Agent

很多人用AI，还是一句一句问：先总结，再改一下，再做个表。这样本质上还是人在带着AI走流程。真正适合Agent的方式，是把一项完整工作连同输入、目标、限制、输出和保存位置一次性交出去。

## 一、把“问题”改成“任务”

不要只说“帮我看看这些资料”。应该告诉Agent：材料在哪里、要完成什么、代表哪一方、重点关注什么、最终交付什么。任务越完整，Agent越容易连续执行，而不是每一步都回来等下一句指令。

## 二、输入和输出都要明确

输入最好直接指向具体文件、文件夹或MCP；输出要明确到DOCX、Excel、Markdown、PDF等格式以及保存目录。法律工作还应说明不得覆盖原始文件、无法确认的事项要标记、完成后列出需人工确认的问题。

## 三、让Agent自己处理中间步骤

如果目标已经清楚，不必自己先拆成十几个小提示词。可以让Agent先读取材料、盘点、分析、生成文件并自检。律师把精力放在任务定义和最终复核，而不是陪着AI逐句工作。

## 直接复制的实战提示词

请处理【任务名称】。输入材料位于【文件/文件夹绝对路径】，重点查看【具体文件或MCP】。请根据现有资料完成【具体工作】，代表【我方立场】，重点关注【事项】。最终输出【DOCX/Excel/Markdown/PDF等格式】至【输出目录】，不得覆盖原始文件；无法确认的事实标记【待确认】，完成后列明生成文件及需要人工复核的事项。

## 最后记住一句话

不要把Agent当成需要你逐句指挥的聊天工具。**能完整交出去的工作，就尽量完整交出去。**
