# 诉讼策略与案件评估教程

> 诉讼实战系列（二）｜适用：AI智能体（元典/北大法宝案例检索 + 企查查/天眼查主体调查）｜2026-08-27
> 用途：起诉（或应诉）前，用量化依据回答"打不打、怎么打、要多少"。

## 一、它能解决什么问题

接受委托时最需要、也最难拍的三个判断：**胜诉把握、诉讼请求设计、保全时机**。本教程用类案数据 + 主体调查给出量化参考，把"凭经验拍脑袋"变成"有数据支撑的决策"。

## 二、输入材料

- 案件事实材料：【路径】（合同、履行凭证、往来函件、损失依据）
- 我方当事人与对方当事人：【名称】
- 管辖初步意见：【意向法院或合同管辖条款】
- 已知对方资产情况（如有）：【描述】

## 三、AI智能体能力配置

| 环节 | 用什么 |
| --- | --- |
| 类案检索 | 类案检索子代理（或独立会话）→ 元典、北大法宝案例库（按案由/法院层级/审结日期过滤）；注意元典点数，先查余额 |
| 法条依据核验 | 法规核验子代理（或独立会话）→ 北大法宝 MCP 逐字核验 |
| 对方主体画像 | 企业信息库（企查查 MCP 或天眼查）：涉诉记录、被执行、股权冻结、经营异常 |
| 财产线索初筛 | 同上 + 网络核查留痕技能（如 network-check-v3）（供保全参考） |
| 金额测算 | 主对话直接计算（本金+利息+违约金分段表，LPR 口径） |

## 四、标准工作流与提示词模板

### 第一步：请求权基础梳理

```text
读取【案件事实材料】，输出：
1. 可选请求权基础清单（违约/侵权/不当得利等，注明竞合关系）；
2. 每项请求权基础的构成要件—事实—证据对应表（缺证的格子标"待补"）；
3. 诉讼时效起算与剩余期间测算；
4. 每项法条列出条文号，标注是否需核验——需要的一律经北大法宝逐字核对原文后再确认。
```

### 第二步：类案裁判倾向分析（核心）

```text
就本案【案由】【争议焦点】，检索类案并输出倾向分析：
1. 检索范围：【意向法院及其上级法院】近【3】年同类案件；
2. 对每个争议焦点统计：支持率大致水平、常见裁判理由、败诉方主要失分点；
3. 赔偿/给付数额区间：列明样本案件的裁判金额档位及影响因素（本金认定、利息计算方式、违约金调减情况）；
4. 每个统计结论附样本案号清单（不少于【5】个），注明数据来源库；
5. 样本量不足或检索不到的，如实说明，禁止编造数据。
输出为"争议焦点—裁判倾向—样本案号"三列表格。
```

### 第三步：对方主体与履行能力调查

```text
对【对方当事人】做涉诉与偿付能力画像（企查查/天眼查）：
1. 涉诉与被执行记录（金额、状态、是否终本）；
2. 股权冻结、出质、经营异常、破产线索；
3. 关联企业结构与资产转移迹象（一层持股即可，注明穿透边界）；
4. 结论：财产保全的紧迫性建议（高/中/低+理由）。
所有信息注明数据日期；仅作保全决策参考，不作为事实认定。
```

### 第四步：诉讼方案设计（交付物）

```text
汇总以上分析，输出《诉讼策略评估报告》（Word，按律所格式；如有其他项目更优的评估报告模板，优先以该模板为基准调整）：
1. 三档策略建议（激进/稳健/保守），各含请求金额、证据补强清单、预期周期能耗；
2. 诉讼请求逐项设计：本金、利息（起算点与利率口径）、违约金（法院调减风险评估）、诉讼费承担；
3. 财产保全建议：时机（诉前/诉中）、财产线索指向、担保方式；
4. 和解空间预判：对方大概率接受的和解区间推演；
5. 风险披露：证据弱点、时效风险、执行不能风险；
6. 全部法条引用完成北大法宝核验，样本案号完成回库核验，未核验项集中列【待核验】清单。
```

## 五、模板复用原则

评估报告、保全申请书等文书：**优先使用律师提供的其他项目更优模板**，AI 在其上做事实填充与口径调整（映射表替换、最小修改、零残留），不从零起草。

## 六、红线

1. 类案统计是**参考不是预言**——样本偏差、地域差异必须披露，禁止输出"胜诉率XX%"式的伪精确结论；
2. 裁判文书与企业信息一律回库核验，禁止凭模型记忆填写案号；
3. 财产线索仅供申请法院查控参考，不得用于非法途径调查；
4. 最终策略决策由主办律师作出。
