# AI实战08｜邮件和附件太乱？让Agent先整理成一个项目资料包

一个项目最初的资料经常散在几十封邮件和附件里。与其人工下载、改名、归类，不如让Agent先把邮件和附件整理成一个可继续工作的项目资料包。

## 一、邮件正文也属于项目材料

客户经常把关键说明写在正文里，附件只放文件。整理时要同时提取发件人、时间、主题、正文关键说明和附件，不能只存附件。

## 二、识别版本和缺失附件

同名文件可能是不同轮修改，邮件里提到“见附件”却可能没有附件。Agent应识别近似版本、重复文件、缺失或打不开的附件。

## 三、形成项目入口

整理完成后至少生成材料目录、邮件摘要和异常清单，让后续Agent或律师不需要重新翻整个邮箱。

## 直接复制的实战提示词

请整理【指定项目相关邮件/邮件导出目录】及全部附件。逐封提取发件人、日期、主题、正文中的关键项目说明及附件名称，并识别附件重复、版本关系、缺失附件和无法读取文件。请在【输出目录】形成项目资料包，同时生成【邮件与附件索引.xlsx】和【项目材料摘要.md】，不得删除或覆盖原始邮件和附件。

## 最后记住一句话

邮件整理的目标不是“收件箱变干净”，而是：**把散落的信息变成一个可以继续工作的项目。**
